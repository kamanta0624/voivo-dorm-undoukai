## コードのライセンス（案。本人が決めるまで LICENSE・package.json・README は変えない）
今：公開リポジトリに LICENSE が無く、package.json は "ISC"（npm の既定値のまま）。

| 案 | 中身 | 向いている場合 |
|---|---|---|
| A. 権利を留保する（All rights reserved） | LICENSE に「Copyright (c) 2026 〇〇. All rights reserved.」とだけ書き、package.json は "UNLICENSED" と "private": true | 見せるのはよいが、使い回しは許さない。収益化の可能性を残す |
| B. MIT | 誰でも改変・再配布・商用利用できる。著作権表示だけ残す | コードを広く使ってほしい時 |
| C. ソースは公開・利用は非商用のみ（例：PolyForm Noncommercial） | 非商用なら使ってよい | 他人の収益化だけ止めたい時 |

おすすめは A。素材・音声に非商用のもの（ユーレイちゃん・もち子・ついなちゃん・32dot の二次配布の禁止）があるので、コードだけ MIT にしても、ゲームとしての再利用はできないため。

README に足す文の案（どの案でも共通）：
> このリポジトリにはゲームのコードだけが入っています。キャラクターの立ち絵・ドット絵・音声・効果音・マップチップなどの素材は含まれていません（各素材の権利者の規約に従って、別に用意しています）。登場キャラクターと音声の権利は各権利者にあります。クレジットはゲーム内の「クレジット」を見てください。
