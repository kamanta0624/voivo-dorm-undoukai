# スマホ実機での確認手順（LAN内・HTTPS）

PC（開発機）と同じ Wi-Fi にスマホをつなぎ、PC で動かしているゲームに HTTPS で入る。
HTTPS のときだけ、ゲームサーバー（2567番）への通信は Vite の中継（`/colyseus`、vite.config.ts）を通る。

## 1. 証明書を作る（初回だけ）
mkcert で、PC とスマホの両方が信頼する証明書を作る。

```sh
brew install mkcert
mkcert -install                       # PC に認証局を入れる
ipconfig getifaddr en0                # PC の LAN の IP（例: 192.168.1.4）
cd ~/kiritan_zunda_proto && mkdir -p certs
mkcert -key-file certs/key.pem -cert-file certs/cert.pem 192.168.1.4 localhost   # IP は上で調べたもの
open "$(mkcert -CAROOT)"              # rootCA.pem がある場所を開く
```

IP が変わったら `mkcert -key-file ...` だけやり直す。

## 2. スマホに認証局を入れる（初回だけ）
- **iPhone**
  1. rootCA.pem を AirDrop で送る。
  2. 設定 → 一般 → VPNとデバイス管理 → プロファイルをインストール。
  3. 設定 → 一般 → 情報 → 証明書信頼設定 → mkcert のルート証明書をオンにする。
- **Android**
  1. rootCA.pem を端末へ送る。
  2. 設定 → セキュリティ → 暗号化と認証情報 → 証明書をインストール → CA 証明書。
  3. 項目名は機種で違う。

## 3. HTTPS で起動する
```sh
HTTPS=1 npm run dev
```
表示される `Network: https://192.168.1.4:5173/` をスマホのブラウザで開く。
- PC は今までどおり `http://localhost:5173/` でも入れる。
- HTTP と HTTPS のどちらで入っても同じ部屋になる。
- Mac のファイアウォールが 5173番への接続を聞いてきたら許可する。

## 4. 確認すること
- **横向きで遊ぶ**：縦向きだと「横にして遊んでね」が出る。
- **操作**
  - 左半分に触れるとスティックが出る（離すと止まる）。
  - 右下のボタン：攻撃・技（クールタイム表示）・設置/帰還（短押しで設置、3秒長押しで帰還）・照準（一番近い → HP → 大将 → 手動）。
  - 照準が「手動」の時、技はスティックで向いた方向へ出る。
  - 倒されている間は、スティックで視点を動かせる。
- **全画面（PWA）**
  - iPhone：Safari の共有 → ホーム画面に追加。ホーム画面から開くと全画面になる。
  - Android：Chrome のメニュー → ホーム画面に追加（またはアプリをインストール）。
- **再接続**：ホームに戻って5秒以上たってから戻ると、つなぎ直して同じキャラを操作できる。30秒以内なら同じキャラに戻る。その間は Bot が代わりに動かす。
- **対戦**：PC 1台とスマホ 1台が同じ部屋に入り、PC で「開始」を押すと対戦できる。
- **重さの計測**
  - URL に `?perf=1` を付けると、左下に「視界の計算」と「フレーム間隔」の平均・最大が出る。
  - フレーム間隔が 16.7ms を大きく超えるなら重い。

## 注意
- Safari のアドレスバーが出ている時は、画面が等倍に収まらないので少し縮小して表示する。全画面（PWA）なら等倍。
- `certs/` は端末ごとの秘密鍵なので、他人に渡さない。
