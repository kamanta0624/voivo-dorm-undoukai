# botai2 報告：Bot のマクロを磨く（層 u・a・e）

2026-11-27。前提は docs/botai_report.md（botai1）。実験は `npx tsx tools/botai.ts --n 20` → `--n 20 --extend`（差が分からない組だけ 40試合まで）、集計は `npx tsx tools/botai2_report.ts`。
物理（操作の上手さ）はすべて中。本番・練習の Bot は今のまま（中・std、層なし）。固定シードの Bot 戦（golden）は変更前と一致。

## 1. 足した層（全マクロ共通。CONFIG.BOT_LAYER。マクロ名は「土台+層」、例 rush+uae）
Bot の判断（docs/botai_report.md の 2-1 の 1〜7）は今のまま。層は最後の「役割」を、条件が合う間だけ差し替える。優先は e ＞ u ＞ a ＞ 土台の役割。

| 層 | 中身 | 決めた値と理由 |
|---|---|---|
| u（パワーアップしたら攻める） | パワーアップ中の Bot は役割に関係なく「攻め」（敵の大将の部屋を見回り、見えたら大将を攻撃）。終わったら元の役割に戻る | − |
| a（アシストと足並みをそろえる） | 味方のアシストが出ている間、アシストに近い生存中の Bot 2人を「同行」にする。同行役はアシストのそば（80 以内）へ行き、アシストから 200 以内の見える敵と戦う。**アシストは、同行役が2人とも 200 より遠い間は進まずに待つ** | 2人: 4人中2人なら残りで資材・攻めを続けられる。近い順: 駆けつけが早い。待つ: 単騎で攻め込んで倒されるのを防ぐのが目的なので、同行役がそばに来るまで止める（同行役が倒れていれば待たない） |
| e（終盤リードしたら守る） | 残り 60秒で、大将HPの割合が相手より上なら、全員「守り」。自陣の大将から 300 以内の見える敵を迎え撃つ（いなければ大将のそばで待つ） | 守りの直し（下の2章）を入れた |

- adv は廃止、常駐の guard も廃止（botai1 の結果は logs/botai と docs/botai_report.md に残る）
- 記録部の Bot の状態に escort（同行）・ultraid（パワーアップ中の攻め）を足し、守りは guard に分けた。チームごとに「終盤の守りに入ったか」（endDefend）を記録

## 2. botai1 で守りが効かなかった理由（調べた結果と直したこと）
guard 対 std を6試合回し、guard 側の大将が攻撃された瞬間（110回）の守り役を見た。
- 攻撃しているキャラは守り役の組から見えていた（133件中123件）が、**守り役から 250 より遠いことが多かった（133件中59件）**。Bot が戦う相手は「自分から 250 以内」なので、大将の反対側から撃たれても守り役は戦わず、大将のそばで待っていた（守り役の状態が「待機」50件）
- 守り役が倒れていることも多かった（攻撃された時に2人とも倒れていた 29回、1人だけ 29回）。2人で相手の攻め役とアシストを相手にしていた
- **直したこと**: 守りの間は「自陣の大将から 300 以内の見える敵」を、守り役からの距離に関係なく迎え撃つ。人数は e で全員にした

## 4. 要約
- **u（パワーアップしたら攻める）**: std+u は 55%（40〜69%、差が分からない）。パワーアップ中に攻めていた時間は1試合4人で 45秒ほどしかなく（パワーアップが短く、撤退中・戦闘中は層が効かないため）、効きは小さい。悪くはしない
- **a（アシストに同行）**: **std+a は 20%（8〜42%）で std に負ける**。同行で2人が持ち場を離れ、アシストが待つので攻めが遅れ、デスも増える（29.5）。足並みをそろえるより、アシストを単騎で突っ込ませる今のままの方が強い
- **e（終盤リードで守る）**: std+e は 57%（差が分からない）。守りに入った試合の勝率は 84% だが、守らない std がリードした時の勝率（90%）より低い。**リードしている時は守らずに攻め続けた方が勝つ**（大将を削り続ける方が、時間切れの大将HP比べでも、倒し切りでも得）
- **u・a・e を全部足すと**: std+uae 45%・rush+uae 50%（どちらも差が分からない）。rush は層なしの方が強い（rush 75% 対 rush+uae 50%）。farm は farm+uae で 0% → 15% に上がるが std には勝てない（パワーアップ中の攻めと同行で、キャラの大将ダメージが 53 → 424 に増えたが、std の 600 前後には届かない）
- botai1 と同じく、**勝敗を決めているのは敵の大将を削る量**。層はどれも「攻める時間」を減らす方向に働くもの（a・e）が負け、攻める時間を足すもの（u）だけが少し良い

## 5. 本番に入れるか（本人の判断のための材料）
- 今の結果では、本番の Bot（std）に入れて強くなる層はない。入れるなら u だけ（悪くしない、少し良い可能性）
- a と e は今の作りでは弱くなる。a は「同行役がアシストの前に出て盾になる」「アシストは待たない」、e は「守りではなく攻めの継続」の方が良い可能性があるが、今回は試していない
- Bot は人間と動きが違う（人間は寄り道・慎重さが Bot と違う）。人間の試合のログが少なく（4試合）、人間に当てはまるかは未確認
