# botai3 報告：rush に対するメタのマクロがあるか

2026-11-27。前提は docs/botai_report.md・docs/botai2_report.md。実験は `npx tsx tools/botai.ts --plan botai3 --n 20` → `--extend`（差が分からない組だけ 40試合）、集計は `npx tsx tools/botai3_report.ts`、徳の入り方は `npx tsx verify/botai3_toku.ts`。物理はすべて中。本番・練習の Bot は今のまま（中・std）。固定シードの Bot 戦（golden）は変更前と一致。

**結論: rush に勝ち越すマクロは無かった（95%区間の下限が 50% を超えた組なし。一番近いのは rush+w の 65%、区間 50〜78%）。**

## 0. 徳の入り方
botai1・botai2 のログには資材の種類ごとの数が無いので、記録部に「拾った資材の種類と自陣／敵陣」を足し、固定シード20試合（std vs std）で数えた。1試合1チームあたり。

| 資材の種類（コードの区分） | 1個の徳 | 取得数 | 徳（名目） |
|---|---|---|---|
| コバコが中立に配る資材（高性能の徳 materialBig） | 0.4 | 44〜51 | 17.6〜20.3 |
| 自陣の裏側の部屋の資材（materialBack） | 0.4 | 67〜70 | 26.8〜28.0 |
| 敵陣の裏側の部屋の資材（materialBack） | 0.4 | 7〜9 | 2.8〜3.5 |
| 表側（食堂・中央）の資材（material） | 0.2 | 33〜34 | 6.5〜6.8 |

（資材は 70% が裏側の部屋に湧く。徳は 0〜10 で止まるので、実際に増えた量は名目より少ない）

| 徳の増減の内訳（1試合1チーム、std vs std） | |
|---|---|
| 資材 合計 | +約50 |
| 反省中（撤退中の人数 n に毎秒 0.05×n²） | +14〜15 |
| 手配犯を倒した | +9 |
| KO（−1.5） | −20〜−22 |
| 攻撃（−0.06／発） | −14〜−16 |
| コバコを攻撃 | −9〜−11 |
| 盗み食い | −10 |
| 壁を壊した | −8〜−9 |
| スロット当選（−2） | −7〜−8 |

- **本人の見立てとの照合**: 「コバコの資材が大きい」は合っている（1チーム 18〜20）。「自陣の資材は大して得られない」は**合っていない**。自陣の裏側の部屋の資材が一番の稼ぎ（約28）。表側の資材（0.2）は小さい（約7）。敵陣の資材は、std の Bot はほとんど取りに行かない（約3）
- **撤退中の徳（n²）**: 撤退の長さを T 秒とすると、4人がばらばらに撤退すると 4×0.05×1²×T＝0.2T、4人そろって撤退すると 0.05×4²×T＝0.8T（4倍）。復活までの秒数（3＋怒り×0.1、最大15秒）で T＝8 なら 1.6 と 6.4、T＝15 なら 3 と 12。ただし徳は 10 で止まる

## 1. 作ったマクロ（CONFIG.BOT_MACROS・BOT_COUNTER）
Bot の判断の土台は botai1・2 と同じ（近くの敵と戦う・低HPで帰る／逃げる、など）。マクロは「何もない時にどこへ向かうか」。

| マクロ | 中身 |
|---|---|
| steal（盗み） | std と同じ割り振り（資材2・攻め2）。資材役は、コバコの資材と敵陣の裏側の資材が残っていればそれを優先して取りに行く（無ければ近い資材） |
| counter（迎撃→逆襲） | 開始時は全員で自陣の大将のそばに構える（大将から 300 以内の見える敵を迎え撃つ。botai2 で直した守り）。敵が2人以上撤退中になったら全員で敵の大将へ攻める。攻め始めたら、敵が復帰しても戻らない。味方が全員撤退中（全滅）になったら、復帰後に構えへ戻る |
| split（入れ違い） | 2人は counter（構え→逆襲）、2人は rush と同じく攻める |
| 層 w（一斉撤退） | 味方の誰かが撤退中の間、残りの味方は帰還・逃げをやめて攻め切る（なるべく早くそろって撤退する）。rush+w・counter+w を作った |

## 3. 足りなかったもの（rush に勝てなかった理由）
- **大将ダメージ**: 勝敗はここでほぼ決まる。rush は相手が何でもキャラの大将ダメージ 745〜946 を出す。対抗できたのは、同じくらい攻める rush+w（889）・counter（821）だけで、互角止まり
- **徳・スロット**: steal・std・farm は徳を稼ぎスロットも当たる（2.5〜4.8回、rush 側は 1.0〜2.4回）が、大将ダメージの差を取り返せない。farm は対 rush 0%
- **守り（counter の構え）**: counter は平均 4回逆襲に入るが、構えている時間は全体の 9% だけで、すぐ逆襲に入って結局 rush と同じ動きになる。構えて受けることで得をしていない（守りが勝敗に効かないのは botai2 と同じ）
- **一斉撤退（w）**: rush+w は rush に 65%（50〜78%）・std に 70%（55〜82%）で、今回いちばん良い。counter+w は counter より悪い（対 rush 38%）。逆襲を始めると戻らないので、w が攻めをさらに増やすだけになった

## 4. 気付いたこと・調整の案（数値は変えていない）
- **rush に勝つ方法が「rush を強くする」しかない**のは、大将へのダメージの価値が大きすぎるため（botai1 の指摘と同じ）。案: 時間切れの判定に徳やスロットの成果を混ぜる／大将の近くで受けるダメージや反撃を強めて、攻め続ける側の撤退を長くする／撤退中の徳（n²）を大将ダメージの代わりになる量へ増やす
- **steal は対 std に 75%（60〜86%）で勝つ**。コバコの資材を 54〜64個、敵陣の資材を 19〜29個取り、スロットのアシストの大将ダメージ（160〜193）も伸びた。資材の取り合いには意味がある。ただし rush には勝てない
- 敵陣の資材は 1個 0.4 と自陣と同じなので、取りに行く危険の割に得が無い。案: 敵陣の資材の徳を上げる（本人の「敵陣に乗り込んで盗む」の狙いに合う）
- Bot と人間は動きが違う。人間の試合のログは少なく（4試合）、人間に当てはまるかは未確認
