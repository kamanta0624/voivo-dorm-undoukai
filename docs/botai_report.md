本番・練習の Bot は「中・std」のまま（固定シードの Bot 戦 golden が変更前と完全一致）。

## 2. マクロ（チームごと。CONFIG.BOT_MACROS）

### 2-1. Bot の動きの土台（どのマクロでも同じ）
Bot は毎tick、上から順に当てはまったものを1つ行う（bot.ts の botThink。2026-11-28 の refac2 までは GameRoom.botThink）。マクロが変えるのは最後の「役割」だけ。
1. **帰還**: HP が 30% 未満・自陣の給湯室の外・脅威なし（見える敵なし、1.5秒以内に被弾なし）なら帰還の溜めを始める（溜め中は止まる）
2. **技**: CT が明けていて、技の範囲に相手がいれば使う
3. **近くの敵と戦う**: 自陣営から見えていて 250 以内の敵（手配犯を優先）に向かって通常攻撃
4. **低HPで脅威あり**: 敵の残りHPが自分以下なら戦う、それ以外は自陣の給湯室へ逃げる
5. **ご飯**: 給湯室にいてHPが満タンでないなら食べに行く
6. **コバコ**: 90 以内なら倒しに行く（落とした荷物をすぐ拾える位置の時だけ）
7. **荷物**: 見えている荷物を拾いに行く
8. **役割**（ここだけマクロで変わる）
   - **gather（資材集め）**: 一番近い資材（徳）を拾いに行く
   - **raid（攻め）**: 敵の大将がいる候補の部屋（3部屋）を近い順に見回り、大将が見えたら大将を攻撃
   - **guard（守り。今回足した役割）**: 自陣の大将のそば（大将の半径の3倍以内）まで行って待つ。近づいた敵は 3. で迎え撃つ

つまり、どのマクロでも「近くに敵がいれば戦う」「低HPなら帰る・逃げる」は同じで、マクロは「何もない時にどこへ向かうか」を決める。

### 2-4. マクロごとの読み取り
- **rush（90%）**: 4人全員が敵陣へ行くので大将ダメージが最大（875）。そのぶんデス（30.7）と撤退中の時間（24%）が最も多く、悪行で徳を大きく減らす（−21.8）。徳が下がるのでスロットの当たり・パワーアップは最少だが、それでも勝つ。半分以上の試合で大将を倒し切る
- **std（74%）**: 攻め2人で大将ダメージ 600。徳はほぼ横ばい。rush 以外には勝ち越す
- **adv（45%）**: 「人数有利の時だけ攻める」は、両チームとも撤退中の人が出入りするので有利になる時間が短く、実際に攻めていたのは 9% だけ。ほぼ farm と同じ動きになり、大将ダメージが足りない
- **farm（32%）**: 徳を一番稼ぎ、スロットもよく当たり、アシストが大将を削る（245）が、キャラの大将ダメージが 94 しかなく、時間切れの大将HP比べで負ける。大将を倒し切れない（撃破勝ち 2%）
- **guard（8%）**: 守り役が自陣の大将のそばで待つが、**自陣の大将の残りは一番少ない（39%）**。相手の攻め役は大将の部屋の手前の戦闘で止まらず、大将の反撃と一緒に戦っても守りきれていない。攻めがゼロなので大将ダメージも最小
- 全体: **勝敗は「敵の大将に与えたダメージ」でほぼ決まる**。徳・スロットで得をしても（farm・adv）、大将を削る量の差を取り返せない

## 4. 要約
- **フィジカル差1段階（今の作り）で勝率はほぼ動かない**。40試合では差が出ず（±15% 程度の幅に埋もれる）、10% の差を見分けるには1組み合わせ約100試合が要る。今の Bot の「上手さ」で変えられる所（気付く速さ・技の遅れ・狙う相手）は勝敗への効きが小さい
- **マクロの違いで勝率は大きく動く**（同じフィジカルで rush 90% 〜 guard 8%）。勝ち負けをほぼ決めているのは「敵の大将をどれだけ削るか」。時間切れも大将HPの割合で決まるので、大将を削らない farm・guard は負ける
- **戦略はフィジカル差を埋められる**: 弱・rush が強・std と互角（強の勝率 40%、差が分からない）
- 引き際（帰還・逃げる判断）を慎重にすると負ける（2回目の実験）。攻め続けた方が大将ダメージで得をする

## 5. 気付いたこと（数値の調整案。実際の数値は変えていない）
- **大将を削ることの価値が大きすぎる**かもしれない。rush の徳は −22/試合と大きく減っている（悪行）のに 90% 勝つ。徳・スロットの効きが大将ダメージに比べて弱い。案: 時間切れの判定に徳を混ぜる／大将の反撃を強める／大将ダメージで徳を少し下げる
- **守りの価値がない**（guard 8%）。大将の部屋で待っても、大将が自分で反撃して倒すので味方の守りが要らない可能性。案: 大将の近くにいる味方に被ダメ軽減など守る理由を作る
- **キャラ別**: rush で特に伸びるのはずん子（大将ダメ 343）・そら（318）・アル（302）・ひまり（284）。ユーレイちゃんはどのマクロでも大将ダメージが低い（std 36・rush 56）。めたん・あいえるたんも大将への寄与が小さい（付録）
- Bot と人間は動きが違う（人間は寄り道・慎重さが Bot と違う）。人間の試合のログは4試合しかなく、この結論を人間に当てはめられるかは未確認
