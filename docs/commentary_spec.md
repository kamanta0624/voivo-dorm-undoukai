- `[A]` = 主役のキャラ（または助っ人）、`[B]` = 相手キャラ、`[C]` = 連携した味方、`[組]` = チーム名、`[大将]` = 大将名、`[助っ人]` = アシスト名、`[技]` = 技名、`[場所]` = 場所名、`[n]` `[m]` = 数。部品は別クリップで連結

# 0. 全体の仕組み：注目度とフォーカス
実況はマップ全体を見ている（中立のTV中継）。ただ出来事を順に読み上げるのではなく、「いま注目している1人（または助っ人）」＝フォーカスについて実況する。

## 注目度
- 対象：全キャラと助っ人
- 出来事が起きると、その座標に近い対象（半径内）の注目度が上がる
- 上限は低い。撃破1回で上限に達する程度
- 時間経過で減る

| トリガー | 上がる量（仮、上限100） |
|---|---|
| 撃破（倒した側・倒された側の周辺） | 上限まで |
| 助っ人の登場 | 60（助っ人本人） |
| 大将に接近（敵の大将側チームの視界に入った。大将本人の視界を含む＝visibleTo） | 40 |
| 回避・ファンネル撃墜 | 40 |
| コバコ撃破（攻撃1回でKO） | 50（撃破したキャラ） |
| コバコの荷物を拾う | 50（拾ったキャラ） |
| 敵を視界に捉える（チームの視界に初めて入った） | 15 |
| ダメージ（与えた・受けた） | 1回10 |
| 時間経過 | 毎秒 −15 |

- パワーアップ（ウルト）そのものはトリガーにしない（スロット当選の実況で兼ねる）。パワーアップ中のダメージ・撃破は通常どおり加算
- 大将への接近は、大将側に見えた時点で判定する。見えていない接近は判定しない（奇襲を実況で漏らさない）

## フォーカス
- フォーカスなしの状態で、誰かの注目度が50（仮）以上になったら、その対象にフォーカスして実況を始める
- フォーカス中の対象の注目度が25（仮）を下回ったらフォーカスを外す（平時の実況へ）
- 他の対象の注目度がフォーカス中の対象を上回ったら、そちらへフォーカスを移す（行ったり来たりしないよう、差が20（仮）以上のときだけ）
- フォーカスが移るときは、場所の前置きを挟んでから実況する（3章）
- 戦闘の実況（1章）と個別プレー（2章）は、フォーカス中の対象が関わるものだけ喋る
- 割り込み（6章の「全体」）はフォーカスに関係なく喋る

# 1. 戦闘の実況（フォーカス中の対象が関わる戦闘）

## 1-1. 戦闘の検知
| 項目 | 定義 |
|---|---|
| 戦闘の開始 | キャラ同士のダメージが発生し、その地点が進行中のどの戦闘の半径にも入っていない |
| 半径 | 視界半径（VISION_RADIUS、仮） |
| 参加者 | 戦闘の半径内にいる両チームの生存キャラ。大将・助っ人・召喚物は人数に数えない |
| 合流 | 戦闘中に半径内へ入ってダメージを与えた／受けたキャラを参加者に追加 |
| 離脱 | 半径外へ出た参加者。生存のまま離脱＝逃走 |
| 戦闘の終了 | 参加者間のダメージが3秒（仮）途切れた |
| 撃破者の扱い | 召喚物（ファンネル等）・技の残留物による撃破は持ち主の撃破。大将・助っ人による撃破は別扱い（1-5-4）。スロットの罰による撃破は撃破として実況しない |
| 撃破にならないもの | パワーアップ中に倒された（元のキャラにHP100%で戻る）。実況しない |
| 連携 | 倒されたキャラへ直近5秒で与えたダメージが30%以上の、撃破者以外の味方（最大の1人＝[C]） |

1戦闘で喋るのは最大で「接敵1・合流1・撃破（単発ごと）・連続1・追跡1・まとめ1・盤面1」。
