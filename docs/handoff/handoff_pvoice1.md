# handoff_pvoice1：プレイヤーボイスの台本（本人レビュー用）

## 目的
プレイヤーキャラのボイス（試合中にキャラがしゃべる声）の台本を作り、本人がスプレッドシートで見て直せる形で渡す。**台本づくりだけ。コード・音声・素材は触らない。反映なし・タグなし。**

## やること
1. 0章：しゃべる場面の候補を一覧にして止める（例：技の発動・撃破した・倒された・復帰・パワーアップ・勝ち負け など。今のゲームにある出来事から拾う）。場面ごとに「本数・誰に聞こえるか（本人だけ／全員）・字幕の有無」の案も付ける。**ここで止めて本人に聞く。**
2. 本人が決めた場面で、全キャラ分の台本を書く。
   - 既存の `docs/char_lines.md`（ビィの「ばくはつ！」）と `docs/voice/sortie.csv`（出撃セリフ）の口調・書き方に合わせる。キャラの口調は docs/char_catalog.md 等を見る。
   - 列：キャラ（id・名前）／場面／番号／セリフ／スタイル（なければノーマル）／メモ
3. `docs/voice/player_voice_draft.csv` に出す（スプレッドシートに読み込める UTF-8 BOM 付き CSV）。出撃セリフと同じく、本人がスプレッドシートで直して置き直す前提。
4. CSV の場所と、場面ごとの本数の集計を報告して**止める（本人のレビュー待ち）**。

## 守ること
- セリフは本人のレビュー前に確定扱いにしない。char_lines.md にはまだ書き足さない。
- 実況（No.7・ニア）の台本は別物なので触らない。
