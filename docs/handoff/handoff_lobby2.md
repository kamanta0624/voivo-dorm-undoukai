## 1. 出撃セリフ
1. docs/voice/sortie.csv のアル・ビィの4本を本人が直した（シート「VOICE SQUAD 出撃セリフ」の最新）。vvproj に反映し（ひまり・ずん子・イタコの読みの直しは残す）、npm run voice:audio で書き出し直す。docs/char_lines.md も合わせる

## 2. タイトル画面で名前を変更できる
3. タイトルの「あなたの名前」を本人が入力して変えられるようにする（今は自動で付いて変更不可）。自動の名前は初期値として残す
4. 決めたこと：空欄なら自動の名前に戻す。長さの上限は定数（仮置き 10 文字）。端末に保存し、次に開いた時も使う（今の sessionStorage のタブごとの自動名は、保存がない時の初期値に回す）。BAN 判定の端末ID（bid）は今のまま
5. 決めていないこと（勝手に決めずに報告）：NG ワード判定、同じ部屋での名前の重複の扱い。今のコードにある仕組みがあればそれに乗せ、無ければ「無い」と報告するだけでよい
6. 名前が出る場所（待機画面の組の一覧・観戦の一覧・管理ページ等）で、変えた名前が使われること

## 3. キャラ選択画面
7. 組の名前：「あんこもん軍」「ずんだもん軍」を「だいだい組」「みどり組」に変える（main.ts の TEAM_NAME）。選択画面以外で TEAM_NAME が出る場所も同じになるので、どこに出るかを一覧で報告
8. 右上の組の一覧の枠（#roster）の横幅を3割削る（今 32% → 約 22%）。文字があふれる場合は止めて案を出す
9. 「タイトルへ」（#totitle）：大きさはそのまま、画面の中央上部へ移す
10. 「実況 ON/OFF」（#cmbtn）と「立ち絵 右/左」（#sidebtn）：大きさはそのまま、組の一覧の枠の下へ移し、丸いボタンにする。画面遷移のボタン（タイトルへ）と、設定のボタン（この2つ）が見た目で別物と分かるようにする（形・色・アイコンなど。案は Code に任せ、スクショで確認する）
11. キャラを選んだ後（OK?・出撃ボタン・出撃済みの間）は、「タイトルへ」を画面の外へ逃がす（立ち絵と被るため）。選択バーに戻ったら元の位置に戻す
12. 「↩️」（#backsel）と「OK?」（#okbtn）を今の倍の大きさにし、今の出撃ボタン（#lobby.sortie #okbtn）並にする。出撃ボタンの大きさは変えない
13. 練習の部屋（#lobby.practice）の表示の出し分けは今のまま
