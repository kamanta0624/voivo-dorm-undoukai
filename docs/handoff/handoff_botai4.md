- 根拠（現行コード）：ソーラーキャノンの大将への総ダメージはチャージ270秒で286、294秒で1200（大将HP 1000）。294秒は射程がマップ対角・壁は即破壊・発射の遅れなし・照射5秒。爆発40%は最初の接触で入り、残り60%は0.25秒おき20回。ビームが当たっている間、大将は拠点移動を始めない。チャージは発射と撤退で0に戻る

## 1. 作るマクロ soracannon（操作は「中」）
1. **そら役（九州そらの Bot 1人）**
   - 技を撃たない（下の発射判断まで）。通常攻撃もしない（悪行を溜めない＝手配されない）
   - 自陣側の裏側の部屋の資材を拾う
   - 敵が見えたら戦わずに自陣の給湯室へ逃げる。帰還を始めるHPの基準は今より高くする（値は CONFIG に仮置き）
2. **残り3人**：自陣の大将のそばで守り（botai2 で直した「大将から 300 以内の見える敵を迎え撃つ」）
3. **発射判断**：敵の大将の残りHP ≤ 今のチャージの大将への総ダメージ（倍率込み）になった時。満たさなくても、チャージが294秒に達したら撃つ（295秒までに発射）
4. **発射の準備（残り15秒から。値は仮置き）**
   - 3人のうち1人が敵の大将を視界に入れに行く
   - 味方は敵の大将を攻撃しない（拠点移動の予告中＝無敵の間に撃たないため）。発射時に敵の大将が予告中なら、明けるまで待つ
   - そら役は、敵の大将へ直線が通る位置（0 で確かめた外周を避ける）へ動いてから撃つ
5. **そら役が撤退した時**：残り時間ではチャージが270秒を超えられない場合、作戦をやめて全員 std の役割に戻る

マクロの中身が上の説明と違う形になる場合は、止めて聞く。

## 2. 比較の実験
- soracannon 対 rush・rush+w・std・steal
- 基準：そら入りの std 対 rush（そらがいるだけの効果と分ける）
- じゃんけんの確認（botai3 で見えた形。2026-11-27 追加）：counter 対 rush、counter 対 std、rush 対 std の3組を各100試合（この試合数だけは下の20試合ルールより優先）。「rush ＞ std、std ＞ counter、counter ≧ rush」が成り立つかを報告の最初の方に1行で書く。そら砲と同じコードの版で回す（botai3 の数字と混ぜない）
- 1組20試合、陣営を入れ替えて半分ずつ。差が分からない組だけ20試合足す。公開サーバーに人がいる間は止める
- 表は botai3 と同じ項目に次を足す：発射まで行った試合の割合、発射時のチャージ秒と敵の大将の残りHP、そら砲の大将ダメージ、そら役の撤退回数、発射前に自陣の大将を倒された試合の割合
