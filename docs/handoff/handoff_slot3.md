## A. モード
1. 試合のスロットを、クラシック（現行）とモダン（slot2 のモジュール）で切り替えられるようにする。既定はモダン
2. 切替の置き場所は確認事項。決まるまで定数1か所

## B. 試合との接続
3. 徳：抽選・保留は陣営の徳を使う。当選のたび徳 −1（slot2 B章）
4. 払い出し
   - 初当たり：アシストLv1／Lv2を召喚
   - CT・引き戻しの当選：パワーアップ・アシストのレベルを+1・+2
   - Lv4以降は「Lv4+N」。1段ごとの強化（仮置き）：攻撃・最大HP（パワーアップはシールド）を Lv4 の値から+5%ずつ。上限なし。オーラの大きさ（handoff_playtest1 H章）は Lv4 のまま
5. 転落・引き戻し失敗のペナルティ：ダメージ または 反省時間追加＋速度ダウン
6. コバコ撃破：得られるアイテムを高確率保留に変更（既存の効果は廃止）。撃破時の徳ペナルティを大きくする：仮置き −3（既存のコバコ襲撃の減少に加算か置き換えかは現行値を見て報告）
7. 演出の表示範囲：実際の視界・キルログ域に合わせる（slot2 D章29）
8. 実況：リーチ・当選・転落のセリフは既存の仕組みに乗せる。新規セリフは台本と vvproj に入れたところで止めて報告（調声は本人）。実況のレベルアップのセリフは Lv4+N でも既存のまま

## 成功基準
1. verify に追加：
   - 払い出しでアシスト・パワーアップのレベルが正しく上がる。Lv4+N の強化量が4どおり
   - 転落・引き戻し失敗でペナルティと速度ダウンが入る
   - コバコ撃破で高確率保留が積まれ、徳が減る
   - クラシック切替で現行の挙動・verify 結果が変わらない
2. Bot戦3試合：初当たりまでの秒数・初当たり時の徳・連チャン数・最高到達レベル・転落回数・ペナルティ回数、徳の推移、試合時間・決着内訳を報告
3. スクショ（PC・スマホ幅）：試合中のリーチ演出が視界・キルログに被らない、全回転、Lv.4+N の表示
4. `npm run typecheck`、verify 一式が通る。e2e は増やさない

## 確認事項（仮置きで進め、報告で挙げる）
- ペナルティ：ダメージと反省時間追加はどちらをどう選ぶか（ランダム／交互）、対象はチーム全員か。量は仮置き（最大HPの20%、反省+3秒）
- 速度ダウン：対象・倍率・時間（仮置き：チーム全員の移動速度×0.8、20秒）
- アシスト不在時のアシスト+1、パワーアップ未発動時のパワーアップ+1（仮置き：新たに発動・召喚）
- モダン／クラシックの切替を部屋設定・タイトル・定数のどこに置くか

## 不明なら止めて聞く
