対象：~/kiritan_zunda_proto
前提：handoff_select_ui.md、handoff_playtest1.md、handoff_commentary.md（実況2含む）実装済み。推測せず現行コードを読んで合わせる

## 公開サーバーを落とさない（最優先）
友人テストの公開サーバーは稼働中。改修・検証・反映のどの段階でも止めない。
- 改修とビルド確認は別フォルダで行い、稼働中の公開サーバーのフォルダやポートを使わない
- 反映は確立済みの無停止手順：cloudflaredは止めずURL維持 → 別フォルダでビルド確認 → share.shをkill -9 → ゲームサーバーだけ差し替え → distへコピー → 同ポートで再起動
- 反映後、公開URLが同じまま新しい版になっていることを確認して報告
- 手順どおりにできない事情があれば止めて聞く

## 成功基準

### A. キャラ選択画面
1. 選択バーを左右スワイプ（タッチ）・ドラッグ／ホイール（PC）でスクロールできる。全キャラに到達できる。段は1段のまま（段数を増やす仕組みは先回りで作らない）
2. 立ち絵は選択バー表示中から中央寄りに出し、左上のステータス窓・右上の組の一覧に顔が被らない位置・サイズにする（今は右上の組一覧の裏に顔が入っている）。立ち絵の加工はしない（拡大縮小・位置のみ）
3. ステータス窓に技名と説明文を追加。技名は技名定義を参照（ハードコードしない）。説明文はキャラ定義（shared/chars.ts）に1項目足して持つ。文面は既存の定義・char_catalog相当から取り、該当がないキャラは仮文を入れて一覧を報告
4. 将来「スタイル」選択（同キャラで性能違い）を足す予定があるが、今回は何も作らない

### B. 対戦中
5. キルログは最大3行。各行の寿命3秒で消える。4行目が来たら最古を消す
6. 被ダメージ表示
   - 被弾キャラを点滅させる（全段階共通）
   - 小ダメージ：点滅のみ
   - 中ダメージ：ダメージ量に比例したサイズ・規模のヒットエフェクト
   - 大ダメージ（一定以上）：派手なエフェクト（大きさ・粒数・揺れなど）
   - 段階の閾値は被弾側の最大HP比で定数1か所（仮：小＜10%、中10〜30%、大≥30%）
   - 既存のエフェクト素材（handoff_fx1）を優先して使う。見せ方の参考探しにWeb検索してよい。外部素材を使う場合はライセンスを確認し出典を報告
   - 立ち絵・32dot素材は加工しない（エフェクトは重ねるだけ）
7. 自分が撃破された時の撃破演出で、キャラを中央に寄せる。距離感は自分が撃破した時の演出に合わせる（そちらは変えない）

### C. 試合後
8. 試合終了後に待機画面へ戻ると、前の試合のキャラで「出撃済み」になっている。これをキャラ選択（選択バー表示・未出撃）まで戻す

### D. バランス（個人の悪行）
9. コバコ撃破で溜まる悪行を現行の3倍、壁破壊を現行の2倍
10. 撤退時に悪行を0にしない。反省時間中は毎秒一定量ずつ減る（0で止まる）。減少速度は「コバコ撃破1回分（変更後の3倍値）の悪行を10秒で減らす」量で、定数1か所。復帰後は減少停止
11. エンマビーム（悪行比例）・指名手配など悪行を参照する処理が変更後も整合することを確認

### E. 実況
12. 「5分」「3分」の「分」を「わけ」と読んでいる。正しい読み（いっぷん・にふん・さんぷん・よんぷん・ごふん…）にする。原因（部品の分割・読みの指定）を調べ、台本ファイル側で読みを固定。vvproj再生成で他項目の調声を消さない
13. 沈黙が1秒続いたら雑談（平時の話題・盤面全体へのコメント）を入れる。秒数は定数。前回の0.5秒ルールが効かず沈黙が多い原因（クールタイム・キュー破棄・条件の狭さ等）を調べて報告
14. 話題のクールタイム：一度触った話題（フォーカスの種類・話題カテゴリ単位）は最低5秒同じ話題を出さない。秒数は定数
   - 例：「全員反省中！大チャンス！」の連続、スロット出目の話の連発を防ぐ
   - 決着は対象外
   - 話題カテゴリの分け方は現行のイベントキー群から決めて一覧を報告
15. 台本仕様（commentary_lines.md）と矛盾する箇所はこの書類を優先。リポジトリ内の台本ファイルも合わせて更新

### 検証
16. スクショ（PC・スマホ幅）：スクロール後の選択バー端／立ち絵と窓の重なりなし／技名・説明文／キルログ3行と消滅／被ダメ小中大／被撃破演出／試合後の選択画面
17. Bot戦の実況ログで、同じ話題カテゴリが5秒以内に重複しないこと、1秒超の沈黙の回数・合計時間（変更前後）を報告
18. 悪行：コバコ撃破・壁破壊の加算量、反省中にコバコ撃破1回分が10秒で0になること、0未満にならないことを単体テストで確認
19. 既存の単体テスト・verify が通る
20. 公開URLが変わらず、新しい版が反映されている

## 不明なら止めて聞く
- 説明文の該当がない・技が複数あるキャラの書き方
- 「出撃済み」がサーバー側状態で、戻すと開始条件（15秒猶予など）に影響する場合
- 悪行の減少が既存仕様（指名手配の解除条件など）とぶつかる場合

## 禁止
範囲外の変更、不要な抽象化（段数・スタイルの先回り）、立ち絵・32dot素材の加工、e2eテストの追加、`npm run share`・1ポート配信・cloudflared周りの変更、公開サーバーの停止
