# Code引き継ぎ：リーチ実況の条件を緩める
対象：~/kiritan_zunda_proto
前提：handoff_ending1.md 実装済み（d239725）。公開版への反映が先に終わっていること

## 背景（0回の原因）
- リーチを言える窓は2つ目のリール停止〜3つ目の停止の1.5秒（SLOT.spin 5 × (1 − 0.7)）
- 現行条件は「雑談がクールタイム中（言い始めから topicCd 5秒以内）」＋「沈黙 fill.silence 1秒の後」
- 雑談は中央値28文字で約4〜5秒。言い終わり＋1秒の時点でほぼクールタイムが切れており、構造的に成立しない

## 成功基準
1. reachFill の条件を変更
   - 「雑談がクールタイム中」→「直前の発話がつなぎ（雑談または盤面コメント）」
   - リーチだけ沈黙待ち（fill.silence）なし。セリフの切れ目で待ち行列が空なら即言う
   - 雑談・盤面のつなぎより低い優先度は維持（待ち行列にセリフがあればそちらが先、つなぎを差し置いて言わない）
   - 結果確定（3つ目停止・払い出し）で捨てる、reachCd、話題のクールタイムは現行どおり
2. 変更は reachFill と pump の呼び出し位置の範囲に留める

## 検証
3. Bot戦11試合の実況ログで、リーチの回数・リーチ発生（リーチ成立）回数に対する比率を報告。リーチの直前の発話がすべてつなぎであること
4. 既存の単体テスト・verify が通る

## 反映
5. handoff_cm_e2e1.md 3章4の無停止手順で公開版へ反映。cloudflared は触らない。公開URLの画面隅が新しいコミットになったことを確認して報告

## 不明なら止めて聞く
