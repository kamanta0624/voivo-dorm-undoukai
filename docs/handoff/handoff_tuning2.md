# Code引き継ぎ：調整2（大将の新性能・白上・スロット）
対象：~/kiritan_zunda_proto
前提：handoff_tuning1.md 実装済み

## 成功基準
### A. アシストへの反撃倍率
1. BOSS_ASSIST_MULT を 0.85 → 3 に戻す

### B. 大将の新性能
用語：第1形態＝試合開始〜1回目の拠点移動まで、第2形態＝1回目の拠点移動以降
2. 第1形態：現行どおり（近づいた敵への反撃）
3. 第2形態：範囲内の敵全員に、1体ずつ個別に弾を発射
   - 弾はずん子AA相当（見た目・弾速）。着弾地点で爆発し、範囲ダメージ
   - 近づいた敵への現行の反撃も併用
4. 拠点移動の発動時（被ダメ累計が BOSS_MOVE_THRESHOLD 以上）：
   - 無敵になる
   - 予告（範囲表示）→ 広範囲攻撃
   - その後に移動。移動完了まで無敵
5. 攻撃の激しさ＝時間係数×HP係数。攻撃間隔とダメージに掛ける
   - 時間係数：試合開始直後が最大、時間経過で減少
   - HP係数：HPが減るほど上昇
   - 係数の最大・最小とカーブは定数
6. 弾の射程・弾速・爆発半径・ダメージ・間隔、広範囲攻撃の半径・予告秒・ダメージは定数ファイル
7. 予告・弾・爆発は両陣営のクライアントに表示（視界外の扱いは既存の敵の描画ルールに従う）
8. 判定はすべてサーバー側

### C. 白上
9. 大将が白上の攻撃範囲内にいる間だけ、大将に扇形攻撃（性能・範囲・攻撃力は通常キャラのAA相当）
10. 回復は従来どおり並行して行う
11. 大将以外は攻撃しない

### D. スロット
12. 当選確率を下げる：SLOT.rate を現行の 0.7倍（試用値、倍率は定数）
13. バランスブレーカーは連チャン時限定
    - コバコの荷物の抽選から外す（POWER_WEIGHTS のバランスブレーカーを0）
    - スロットでバランスブレーカーに届く連チャンの確率を下げる：バランスブレーカー段階への連チャン確率を別定数にし、初期値 0.25（通常の連チャンは 0.5 のまま）

### 検証
14. verify に追加：
    - 第1形態では弾を撃たず、第2形態で範囲内の敵の数だけ弾が出る
    - 拠点移動の予告〜移動完了まで、大将にダメージが入らない
    - 時間係数・HP係数が仕様どおり変化する（開始直後＞時間経過後、HP低下で上昇）
    - 白上が大将だけを攻撃する
    - コバコの荷物からバランスブレーカーが出ない。スロット初回の払い出しにバランスブレーカーが出ない
15. 大将タイマン（大将は拠点に固定、アシストの強さ「普通」）を玄野・青山・白上で各3回、結果を報告（合格条件なし、参考値）
16. Bot戦3試合の時間・決着内訳・大将に与えたダメージ（プレイヤー／アシスト）を報告
17. スクショ確認：第2形態の弾と爆発、移動前の予告と広範囲攻撃
18. 既存Bot対戦が最後まで動く。verify/server.ts・e2e.ts が通る（仕様変更で期待値が変わる箇所は更新してよい）
