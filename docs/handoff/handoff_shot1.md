# Code引き継ぎ：shot1（通常攻撃の弾が、画面では当たっているのに当たらない件）

2026-11-26 Chat作成。対象：~/kiritan_zunda_proto。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。

## 症状（本人）
ずん子など、遠距離の通常攻撃で相手を追いかけながら撃つと、画面上は当たっているのになかなか当たらない

## Chat がコードを読んで切り分けた結果（Code も確かめること）
1. **弾の仕組み（外れる原因）**
   - オートアタックはサーバーで「今、射程内にいる敵」を選び、その瞬間の位置へ撃つ（GameRoom.ts 1017行目付近、pickTarget → attack）。逃げる相手には射程ぎりぎりで撃つことになる
   - 弾は射程と同じ距離（shoot の `left: range`）だけ飛んで消える。飛んでいる間に相手が離れるので、射程ぎりぎりで撃った弾は届かずに消える
   - 目安（相手の速さ170で計算）：ずん子（射程200・弾速800）は撃った時の距離が約160より近い時だけ、WhiteCUL・あいえるたん（射程150・弾速600）は約110より近い時だけ当たる
2. **描画（当たって見える原因）**
   - 他のキャラは NET_INTERP_DELAY（0.2秒）前の位置で描くが、弾（main.ts 1885行目付近の s.shots）は最新の位置で描いている
   - 逃げる相手の絵は実際の位置より約35px後ろにあるので、届かずに消える弾が画面では相手の絵に重なって見える

## やること（本人の判断：A と C の両方）
### 0. 計測（変更の前後で同じ物を出す）
- 通常攻撃の弾ごとに、結果（当たった／届かずに消えた／壁で止まった）を数える。キャラ別に。matchlog に足して botsim の集計（report.html）に出す形でよい。ログの形を大きく変えない
- 変更前の数字を Bot 戦（固定シード）で取っておく

### A. 通常攻撃の弾を射程より遠くまで飛ばす
- 通常攻撃の弾（キャラの通常攻撃と、パワーアップの遠距離の形。`aa: true` の弾）だけ、飛ぶ距離を射程 × 1.4（CONFIG に1か所、仮置き）にする
- 撃ち始める距離（射程・射程の円の表示）は今のまま
- 技の弾・大将の弾・アシストの弾は変えない

### C. 弾も他のキャラと同じ時刻で描く
- 弾の描画を、他のキャラと同じ NET_INTERP_DELAY 前の時刻にそろえる（弾も他キャラと同じ補間に載せる）
- 当たり判定（サーバー）は変えない。見た目を結果にそろえるのが目的
- 自分の弾は、自分のキャラ（今の位置で描いている）より遅れて出る。手元から離れて見えるなど不自然なら、自分の弾だけ出始めを自分の位置に合わせる案を出して止める
- 相手の弾が自分に当たる見た目（ダメージの表示と弾が重なる時刻）もずれる可能性がある。確かめて、ずれが目立つなら止めて報告

## 成功基準
- 計測：変更前と後で、キャラ別の「当たった／届かずに消えた／壁」の割合を表で報告（Bot 戦・固定シード）。ずん子・WhiteCUL・あいえるたんの「届かずに消えた」が減っている
- 練習モードで、逃げる相手（棒立ちを動かせないなら Bot の試合でよい）を追って撃った時の様子を、前後で短い動画か連番のスクショで残す（スマホ 852×393 DPR3）。画面で相手に重なった弾は当たり、当たらない弾は相手に重ならずに消える
- 他の弾（技・大将・アシスト）の飛ぶ距離は変わらない
- golden は変わる。変わったことを確かめてから作り直してコミット
- typecheck・test:server・e2e（全体1回）が通る。e2e は増やさない

## 禁止
範囲外の変更、不要な抽象化、e2e の追加、公開サーバーの停止、先読み撃ち（偏差撃ち）の実装、当たり判定の変更、弾速の変更
