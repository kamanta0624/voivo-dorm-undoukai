# Code引き継ぎ：tachie2（余白と選択画面の立ち絵を身長に合わせる・低身長組は段ボール箱・九州そらを大きく）

2026-11-27 Chat作成。対象：~/kiritan_zunda_proto。react1 の後にやる（同じ余白の立ち絵を触るため）。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。素材（立ち絵・箱の画像）は加工しない。

## 仕様（本人）
1. **身長表**：ボイボ寮の全キャラ（プレイヤーキャラ・アシスト・大将・実況者など、ゲームに出るキャラ全員）の身長表を作り、参考にする。厳密でなくてよい
2. **低身長組**：足元に段ボール箱の画像（assets_local/nc493982_ダンボールー箱.png、1280×1280）を、キャラより背景側に表示する
3. **九州そら**：公式身長173cmに対して、余白の立ち絵が明らかに背が低すぎる。画面に映る下限を膝下にして（膝より下を画面の下に切って）大きく見せ、明らかに東北イタコより大きくする

## やること
### 0. 身長表（実装の前に出して止める）
- docs/char_heights.md に、キャラ・身長・出典（公式サイト／VOICEVOX 公式のキャラページ／ピクシブ百科事典 など）の表を作る。公式の身長がないキャラ（ずんだもん・あんこもん・ユーレイちゃんなど）は「不明」と書き、見た目からの目安を別の列に置く
- 表と一緒に、次の案を出して止める：
  - 低身長組に入れるキャラ（案：身長表で150cm未満。目安の線は Code が表を見て提案）
  - 箱の大きさ（立ち絵の縮尺で何cm相当にするか）と置き方。Chat の解釈は「箱を足元の背面に置き、キャラは箱の天面に立つ（箱の高さだけ持ち上げる）」。違う読みの可能性もあるので、案の画像で本人に見せる
  - 全キャラを身長に比例した大きさで並べた画像（今の余白の表示の仕方のまま・案の表示の仕方の2枚）

### 1. 表示（本人の確認後）
- 余白の立ち絵（#side）の大きさを、身長表の身長に比例させる。基準は一番背の高いキャラが今の大きさ（余白の高さいっぱい）になる形でよい（案を出してよい）
- 立ち絵の絵の中の「頭頂の位置」と「足元の位置」をキャラごとに chars.json に持つ（react0・react1 で測った値があれば使う）。下が切れている絵（ずん子・WhiteCUL など）は、切れた所を画面の下端に合わせ、足元があるものとして縮尺を決める
- 低身長組は箱を足元の背面に表示する
- 九州そら：膝下より下を画面の外に出す（画面に映る下限を膝下にする）。その分だけ大きく表示し、東北イタコより明らかに大きく見えるようにする
- 対象は選択画面の立ち絵（本人：むしろ選択画面こそ身長に合わせたい）と、対戦中の余白の立ち絵。どちらも同じ身長の比率・低身長組の箱・そらの膝下の切り方にそろえる
- 選択画面で、キャラを選ぶ・切り替える時に立ち絵が微妙にズームする動き（.browse の高さ 80%↔100% の切り替えとその transition）はやめる。立ち絵の大きさは身長だけで決まり、選択の操作では変わらない。顔が情報窓・ボタンに被る場合は、ズームではなく位置で逃がす案を出す
- 撃破のカットインなど他の立ち絵の表示は変えない

- 選択画面でも同じキャラのスクショ（スマホ・PC）。情報窓やボタンに顔が被らない
