## 2. リールの絵柄を9つに
- 1〜9の9絵柄
  - 奇数（1・3・5・9）：その陣営のプレイヤー4人
  - 偶数（2・4・6・8）：今あるアシスト4人
  - 7：その陣営の大将
- 単体画面には試合の編成が無いので、プレイヤー4人は仮置き（今の花丸・小夜・めたん・きりたんでよい）。陣営の切替があるなら大将も切り替える
- 当たりの種類とそろう絵柄の対応
  - 奇数（7を含む）でそろう＝良い当たり：通常時はアシストLv2、CT中は+2
  - 偶数でそろう＝良くない当たり：通常時はアシストLv1、CT中は+1
  - 7は今は他の奇数と同じ扱い。将来は別扱いにする予定なので、7だけ後から変えられる形にしておく
- 絵柄の割り当てと当たりの対応は今後変わりうる。config（SLOT_MODERN）の1か所で持つ
- リーチの外れ目・転落・全回転の出目も9絵柄で破綻しないように。全回転は今どおり同じ絵柄のまま回ってそろう
- 素材は加工しない（表示時の拡大・位置のみ）
