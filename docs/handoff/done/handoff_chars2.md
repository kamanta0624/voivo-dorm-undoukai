## 1. 東北イタコ `itako`
- role：balance。近接。歩行 normal
- 通常攻撃はキツネが行う（攻撃の絵・エフェクトはキツネ）
- 通常攻撃の間隔は他キャラの半分（速度2倍）、1発のダメージは1/2

### 技「狐火」
- 発動：自分中心の円周上に火の玉を複数出し、時計回りに回し続ける（自分に追従）
- 回っている火の玉は敵に当たるとダメージ。当たっても消えない（同じ敵への連続ヒットは間隔を置く）
- 一定時間で消える
- 展開中に再度発動：範囲内で最寄りの敵1体を標的にし、全弾がそれを狙う
  - 各火の玉は回転を続け、標的の方向を12時としたときの9時の位置に来た時点で円から離れ、ホーミングで標的へ飛ぶ（時計回りなので9時で接線が標的方向を向く）
  - 当たるとダメージを与えて消える
- 手本：2段階発動・CT自前管理・追尾弾は `kiritan`、自分中心の持続ダメージは `sayo`
- 仮置き（報告の「自分で決めた点」に書く）：火の玉の数・半径・回転速度・持続時間・ダメージ・連続ヒット間隔・ホーミング速度と旋回性能・CTの開始時点・再発動時に範囲内に敵がいない場合の挙動・飛行中に標的が倒れた／見えなくなった場合の挙動

## 2. ユーレイちゃん `yurei`
- role：support。紙耐久
- 足がなく浮遊。グラフィックは hover の足なし版。キャラの高さ（表示・当たり判定）は他キャラと同じ
- 壁すり抜け：壊せる壁のみすり抜けて移動できる。外周・壊せない壁は通れない
  - サーバーとクライアントの移動予測で同じ処理
  - Bot の経路探索もすり抜けを考慮
  - 弾・視界の遮蔽・他キャラの移動は変えない
- 移動速度は並
- 通常攻撃：威力は普通、間隔は他キャラの2倍（DPS低）

### 技「エンマビーム」
- 光弾が小さい半径の螺旋を描きながら直進する見た目（光弾は複数）。当たり判定は先頭の光弾だけ
- 当たった敵へのダメージは個人の悪行量に比例
  - 指名手配中：即死
  - 悪行0：1ダメージ
  - それ以外：悪行量に比例し、指名手配の閾値手前で最大
- 手本：弾を撃ち命中時に処理は `zunko`
- 仮置き：最大ダメージ・比例係数・弾速・射程・CT・螺旋の半径と周期・光弾の数・壁で止まるか
