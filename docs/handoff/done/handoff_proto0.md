# 目的
合成音声キャラ（ボイボ寮）の2D対戦ゲーム「きりたん軍 vs ずんだもん軍」（4vs4オンライン、1試合5分）の最小プロトタイプを作る。
ゲームのルールが成立しているかを確認するのが目的。見た目やバランス調整は対象外。

# 技術
- Phaser 3 + Colyseus、TypeScript
- 判定はすべてサーバー側（サーバー権威）。状態同期は約20Hz。クライアント側の予測は自キャラの移動だけ
- 調整用の数値はすべて1つのconfigファイルにまとめる（下の数値はすべて仮置き）

# ゲーム仕様
## マップ
- 見下ろし視点、左右対称
- 両端に各陣営の自宅。それぞれ3つの拠点と玄関がある
- 中央が中立エリア
- 壁は移動と視線の両方を遮る

## 大将（NPC）
- きりたん軍の大将はきりたん、ずんだもん軍の大将はずんだもん。プレイヤーは選択不可
- 自宅の3拠点のどこかに立っている。特別な隠し要素はなく、視界に入れば見える
- 攻撃されると、攻撃してきた相手に反撃する
- 同じ拠点にいる間に受けたダメージが閾値を超えたら、別の拠点へ移動する。移動しても耐久は回復せず、被ダメ軽減などもない
- 耐久が0になった陣営の負け

## 資材とチームLv
- 中立エリアに一定間隔で資材が出現する
- 資材を拾うと運搬状態になる：移動が遅くなり、攻撃できない
- 運搬中に倒されると、その場に資材を落とす
- 自宅に持ち帰るとチーム経験値になる。資材の用途はチームLvだけ
- チームLvが上がると、通販カタログが段階的に解放される

## 通販
- 大将が一定間隔で、解放済みカタログからランダムに注文する。プレイヤーは注文に関与しない
- 一定時間後、品物が自宅の玄関に届く。敵も拾える（横取り可）
- 品物は最低3種類：武器強化、罠、バリケード

## 暴れ度ゲージ（プレイヤーごと）
- 撃破、アシスト、物資の強奪、敵大将へのダメージで増える
- 試合中はリセットしない
- 倒されると、持ち物とは関係なく、ゲージ量に応じた数の資材をその場に生成する
- 復活時間 = 基本時間 + 係数 × ゲージ量（上限15秒）。復活地点は自宅

## 視界
- 陣営内で視界を共有する、フォグ・オブ・ウォー方式

## 試合
- 5分のタイマー
- 時間切れ時は、大将の残り耐久の割合が高い陣営の勝ち。同値なら引き分け

## キャラ
- 基本攻撃だけを持つ汎用キャラ1種類のみ。ロール（破壊・工兵・前衛・後衛・索敵）は今回は対象外
- 見た目は仮の矩形か画像1枚で、左右反転と上下の揺れ程度の演出だけ付ける

# 対象外
ロール、マッチメイキング、アカウント、サウンド、本番用の絵、バランス調整

# 完成基準（すべて自分で動かして確認すること）
1. `npm run dev` でサーバーとクライアントが立ち上がる
2. ブラウザで8タブ開くと、4vs4で1つのルームに入れる
3. 資材を拾う → 運搬中は遅くなり攻撃不可 → 自宅に持ち帰ってチームLvが上がる。ここまで通しで動く
4. チームLvに応じて大将が自動で注文し、品物が玄関に届き、敵がそれを拾える
5. 大将が反撃し、閾値を超えると拠点を移る。耐久が0になると試合が終わる
6. 暴れ度に応じて、倒されたときの資材ドロップ量と復活時間が変わる
7. 時間切れ時に正しく勝敗判定される
8. 相手陣営の視界外にいるユニットは、クライアント側に送られない
