# 引き継ぎ：そら ソーラーキャノンの照射時間の変更（handoff_sora2）

前提：bd4b3e3（chars3 反映済み）。不明点は勝手に決めず確認しろ。

## 変更
- 照射時間をチャージ量で変える。今は固定5秒（skill.dur）
  - チャージ4分30秒（270秒）まで：照射0.5秒
  - 270秒から最大（今の最後のキーフレーム294秒）まで：0.5秒→5秒へ伸ばす（線形、仮）
- 1発の総ダメージ（keys の第2列）は今のキーフレームのまま。270秒までは照射が1/10になるのでDPSが10倍になる
- 270秒以降は照射時間と総ダメージが一緒に伸びる（総ダメージは今のキーフレームどおり 110→250、大将へは最後に bossMax 1200）
- 実装案：keys に照射秒の列を足す（例 [5,29,200,0,0.5] … [270,110,550,60,0.5]、[294,250,射程,200,5]）。hitDmg の分母（今は S.dur / S.every の固定）を照射ごとの照射秒から出す
- 0.5秒照射で多段が少なすぎる（every 0.25 で2回）なら、every を短くする案を出して本人に確認
- 照射中の旋回は毎秒6度のまま（0.5秒照射では3度）
- そら本人が止まる時間も照射時間に合わせる
- 技の説明文（desc）・chars.ts のコメントを実態に合わせる

## 維持すること
