# Code引き継ぎ：result1（試合結果画面）

2026-11-26 Chat作成、16:00 に仕様改訂。対象：~/kiritan_zunda_proto。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。**handoff_botsim1.md（記録部と summary()）が済んでから着手**。済でなければ止めて報告。

## 目的（本人）
試合後に、勝敗の流れ（両チームの大将HP・徳・スロットの当たり）と、時間帯ごとの個人の大将へのダメージ・徳の増減を見られる画面を出す。ポケモンユナイトの試合結果（上＝スコア推移グラフ、下＝個人ごとの時間帯別のゴール点数）のレイアウトの発想を使う。ユナイトの画像・ロゴ・文言・素材はリポジトリに入れない。

## 出し方（本人決定）
- 決着後の勝敗バナーの上に「リザルト」ボタン。押すと全画面オーバーレイ。「閉じる」で閉じて既存の流れ（結果→待機画面→次の試合）へ戻る
- 自動では出さない。ボタンを押さなければ従来と同じ。観戦者・人間・Bot だけの試合のどれでも出る

## 画面（本人決定）
- 見出し：勝敗（既存バナーの語を流用）と両チームの最終値（大将HP%）。組の色（だいだい組・みどり組）
- タブ「味方チーム」「相手チーム」。観戦者は「左の組」「右の組」。切り替わるのは下半分だけ（上半分は両チームとも常に出す）
- **上半分＝推移グラフ（2段）**：横軸は試合時間（0:00〜終了、1分刻みの縦罫線）。上段＝徳（0〜10）、下段＝大将HP%（100→0）。両チームの折れ線を重ねる（組の色）。終端に最終値のラベル
  - **スロットの当たり**：上段（徳）の、当たった時刻・そのチームの徳の線の上に、**揃った図柄のアイコンだけ**を置く（文字なし）。アイコンの枠の色は組の色（だいだい・みどり）。対象は払い出しがある当たり。図柄の意味は今のスロットのとおり（payout の対象）：プレイヤーキャラの図柄＝そのキャラのパワーアップ、7＝チーム全員のパワーアップ、アシストの図柄＝アシスト出現（出ていれば強化・回復）。ペナルティ・ハズレは描かない（データには持つ）。近接して重なる時はずらして全部見えるようにする。図柄の絵はスロットのリールで使っているものを流用（新規素材なし）
- **下半分＝時間帯別の個人の数字**。チームのタブ（味方／相手）とは別に、表示を切り替えるタブ「大将ダメージ」「徳」を付ける（初期は大将ダメージ）。
  - 行：タブで選んだチームのプレイヤーキャラ（最大4）＋「アシスト」1行（召喚物の分。徳でアシストに増減が無いなら「−」のまま）。行頭はキャラの顔アイコン（選択画面で使っているもの）、アシスト行は「アシスト」の文字
  - 列：時間帯（区間の幅は CONFIG 1か所、仮置き1分。割り切れない最後の列は端数）。縦の区切りは上のグラフの時間軸と揃える。右端に行ごとの合計
  - 「大将ダメージ」：その時間帯に大将へ与えたダメージの合計（整数、0は「−」）
  - 「徳」：その時間帯の徳の増減の合計を符号つき1つの数字（+3、−2、0は「−」）。稼いだ分と減らした分は別々にデータとして持つが、画面は合計だけ。徳の上限・下限で打ち切られた分は数えず、実際にゲージが変化した量
- キル・デス・コバコ撃破・大将への大ダメージ・ペナルティは**画面に描かない**。データ（summary()）には持ったままにする（botsim1 のとおり）
- スマホ縦持ちでも横スクロールなしで読める（縮めてよい。最小の文字サイズを報告。文字の基準は font1 の UI_FONT_SCALE が済んでいればそれに合わせる）
- 描画は DOM＋SVG（依存なし）。既存の決着演出・バナーの書き方に合わせる。Phaser の外

## データ
- 試合終了時（endMatch）に部屋が全クライアントへ summary() を1回送る（メッセージ名は Code 案）。ended の間に入室した観戦者にも入室時に送る。次の試合の開始で破棄
- 使うもの：徳・大将HP の1秒ごとの推移、スロットの当たり（時刻・チーム・揃った図柄・当たり内容）、キャラ別＋アシストの1秒ごとの対大将ダメージ、キャラ別の1秒ごとの徳の稼いだ分・減らした分（区間への合算は画面側）
- 大きすぎる場合は推移を間引く（1秒→2秒など）。間引いたら報告

## 成功基準
- Bot だけの試合を e2e のフックで1回回し、バナーの「リザルト」を押して、スクショ（PC幅・スマホ幅、味方タブ・相手タブ、大将ダメージ・徳の両表示）
- スロットのアイコンが実際と一致：1試合で、アイコンの数・時刻・チーム・図柄を、スロットのログと突き合わせた表
- 大将ダメージが実際と一致：両チームの全行・全列の合計が、既存の試合ログ（writeLog の bossDmg の player＋assist、チームごと）と合う表
- 徳が実際と一致：全行・全列の合計が、botsim1 のキャラ別の稼いだ徳・減らした徳の合計と合う表
- 試合終了後に入室した観戦者にも出る
- 既存の勝敗バナーと試合後の流れが変わらない
- typecheck・test:server・e2e（全体1回）が通る。e2e は増やさない
