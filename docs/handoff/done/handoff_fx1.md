# Code引き継ぎ：技エフェクト強化＋めたん技変更（fx1）
対象：~/kiritan_zunda_proto
前提：キャラ雛形化・chars1 実装済み。`.claude/skills/char/SKILL.md` に従う（一覧・手順書の更新込み）
目的：技を出したことが一目で分かる画面にする

## 公開中のサーバーを落とさない（最優先）
`npm run share`（ポート2567のサーバー＋cloudflared、dist/ を配信）で友人に外部公開中。
- ポート2567のプロセス・cloudflared を kill・再起動しない。`npm run share` を実行しない
- リポジトリ直下の dist/ を書き換えない（`vite build` は `--outDir` で別ディレクトリへ。通常は不要）
- verify/server.ts・net.ts・input.ts・golden.ts はポートを使わないのでそのまま実行してよい
- スクショ・e2e・`npm run dev` は2567・5173に繋ぐため、そのままでは公開サーバーとぶつかる。ポートを環境変数で上書きできる最小の変更（未指定時は現行の2567・5173のまま。server の listen、vite の proxy と port、クライアント開発時の接続先）を入れ、別ポート（例：2568・5174）で起動する。verify/lib.ts の5173・2567も同じ環境変数に従わせる
- 起動したプロセスは作業後に自分で止める。止めるのは自分が起動したPIDだけ
- 公開を止めないと進めない手順が出たら止めて聞く

## 1. めたん：ドリル（技の作り直し）
- 発動で前方にドリルを一定時間出しっぱなし。ドリルに触れた敵にダメージ＋はじき
- 描画：回転するドリル（コード描画。螺旋の縞が流れる・先端の火花など）。素材PSD・立ち絵は使わない・加工しない
- 手本：持続状態は `sayo`、判定形状は既存の長方形／扇形の道具を流用
- 数値（持続時間・ダメージ・はじき量・同じ敵への再ヒット間隔・ドリル長さ）は chars.ts の `skill` に置く。仮置きし報告

## 2. 小夜：斬撃を派手に
- 疾風乱舞の周期ダメージごとに、円内へ複数の斬線（閃光→残光で消える）＋命中した敵に斬撃ヒット表示
- 挙動・数値は変えない（描画のみ）

## 3. ほかのキャラ：目立たない技の描画強化
- 一覧（docs/char_catalog.md「技の組み立て」）で描画が共通fxだけ・目印だけのキャラを洗い出す。候補：whitecul（rect のみ）、ierutan（目印のみ）、zunko（矢が共通弾のまま）
- 着手前に、10キャラ（めたん・小夜を除く）の技発動スクショを撮り、「強化する／しない」と理由の表を報告してから実装
- 描画のみ。挙動・数値は変えない
