# Code引き継ぎ：walldmg1（壁の段階破壊：無傷→小破→中破→破壊）

2026-11-24 Chat作成。前提：handoff_perf1〜perf4 が完了していること（マップは1枚のテクスチャ＋壊れた範囲だけ texSubImage2D の部分転送、描画の指針 docs/render_policy.md）。
不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。

## 狙い（本人）
壁を抜くのに手数がかかるようにし、鉢合わせを増やして近接キャラを活躍しやすくする。

## 仕様
- 壊せる壁は 無傷→小破→中破→破壊 の4段階。中破までは今の壁と同じ（通れない・視界を遮る・弾を止める）。破壊で今の「壊れた」状態
- 小破・中破は時間で直らない
- 1回の発動で、1マスにつき1段階だけ進む：
  - 花丸パンチ・アルの突撃：1段階
  - そらのソーラーキャノン：1発射で1段階（照射の多段ヒット・爆発を含めても同じマスは1回の発射で1段階まで）。チャージ4分30秒超の発射は即破壊
  - 花丸のパッシブ（壁押し込み）：即破壊
  - ほかに壁を壊す処理があれば洗い出して報告（今の呼び出し元は sora.ts・hanamaru.ts（拳・パッシブ）・aru.ts の breakWalls）
- 1段階で壊しきれなかった壁は「通れない壁」のまま。拳・ビームはそこで止まり、突撃は壁に沿って滑る（今の壊せない壁と同じ扱い）。本人確認済み
- 悪行・徳：1段階進めるごとに今の壁破壊1回分（今は技の発動ごとに1回。その単位のまま段階ごとに入る）。即破壊（花丸パッシブ・そらの4分30秒超）は3段階分を即座に入れる
- Bot：壁破壊で近道する判断（花丸の botMove など）が1段階では抜けないことを踏まえて破綻しないか確認。直す必要があれば最小限で、方針を報告

## 見た目
- 小破・中破の壁に割れ目を重ねる。素材は未定なので、当面は仮の線の割れ目
- 小破・中破ではマップの canvas（paintMap の描き先）に描き込まない。マップの描き直しと部分転送は「破壊」になった時だけで、perf3 の部分転送の経路を使う（refresh() は使わない）
- 割れ目の絵は起動時に1回だけ作り（小破・中破の2種、線で描く）、1枚のテクスチャに2コマとしてまとめる（テクスチャの枚数を増やさない）。壁のマスごとに Blitter（第一候補）か Image で重ねる。毎フレーム Graphics で描き直さない。画面外の割れ目は描かない（Blitter の bob の visible やカメラ範囲での間引き）
- 割れ目の表示物は段階が変わったマスだけ足す・差し替える・消す
- 後で素材に差し替えられるよう、割れ目のテクスチャのキーは1か所で定義

## 通信
- 壁の段階はサーバーが持ち、変わったマスだけをクライアントへ送る（全マスの段階を毎スナップショット送らない）。途中参加・再接続でも今の段階がそろうこと

## 成功基準
- 各技の段階の進み方が上の仕様どおり（サーバー単体テストで確認）
- 中破までは通れず視界も遮り、破壊で通れる
- 悪行・徳が段階ごとに入り、即破壊は3回分
- 壁を削る試合で、GPU 転送量・drawcall・メインスレッド時間が今から大きく増えない（計測は perf2〜perf4 と同じハーネス（ヘッドレス Chrome・CPU 4x・Bot 入り試合60秒×2回）で、?perf=1 の値・GPU 転送量・drawcall・メインスレッド時間を前後で比べる（docs/render_policy.md の7））。割れ目が数百マスになった時の drawcall も報告
- e2e が通る（壁破壊を前提にした既存の e2e は新仕様に合わせて更新）
