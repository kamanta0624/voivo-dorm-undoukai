## 1. 練習モード：相手を選ぶ段階をなくす
本人が遊んで「OK? を押すとキャラ選択に戻る」と不具合に見えた（実際は2段階目の相手選び）。分かりにくいので2段階目をやめる。
- 練習の選択画面は自分のキャラを選ぶだけ。自分を選んで OK? → 開始、で試合が始まる（main.ts の pStage の2段階目をなくす。見出しは「練習: 自分を選ぶ」等、今の1段階目の表示でよい）
- 相手のキャラは、選べるキャラ（PICKABLE）からランダム。相手の動きは「棒立ち」で始まる
- 相手のキャラ・動きは、今までどおり試合中の練習パネルで変えられる
- 練習の「選択画面へ」で戻った時も同じ（自分を選ぶだけ。相手は改めてランダムでよい）
- e2e・サーバーテストで練習の2段階目を前提にしている所があれば合わせる

## 2. もち子のファンネル：クールタイムを30%減らす
