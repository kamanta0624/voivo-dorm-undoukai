## 公開サーバーを落とさない（最優先）
友人テストの公開サーバーは稼働中。改修・検証・反映のどの段階でも止めない。
- 改修とビルド確認は別フォルダで行い、稼働中の公開サーバーのフォルダやポートを使わない
- 反映は handoff_cm_e2e1.md 3章4の手順：試合中でないことを確認 → 別フォルダでビルド・動作確認 → ゲームサーバー（ポート2567、nohup。share.sh の管理外）だけ止める → ビルドを dist/ へコピー → 同じポート2567で再起動。cloudflared は止めない（PIDは現物で確認）
- 反映後、公開URLが同じまま新しい版になっていることを確認して報告

## 成功基準
### A. 選択バーのループ
1. キャラ選択の横スクロール（ドラッグ・スワイプ・ホイール）を左右両端でつなげ、無限ループにする。端で止まらず、継ぎ目が見えない
2. カーソル／1クリックで表示切替・表示中クリックでOK?、の既存操作はループ後も同じに動く（複製したカードでも同じキャラとして扱う）

### B. 決着演出（大将撃破）
3. 大将撃破の瞬間からゲームをスローにする（サーバー側の時間倍率。倍率・秒数は定数）。スロー中は入力を受けない
4. 全クライアントのカメラを倒された大将へ移す → 大将が爆発（既存の撃破演出 KO_FX を大きくしたもの。32dot素材は加工しない）
5. カメラを止めを刺したキャラへ移す → 止めを刺したキャラの立ち絵（Moiky、加工なし）と名前を表示。止めがアシストの場合は立ち絵なしで名前のみ（大将は止めを刺せない）
6. 勝った組を「ORANGE TEAM WIN」形式で表示（組の英語名は組の色の定義から引く：だいだい=ORANGE、みどり=GREEN。8色分。文字色は組の色）
7. その後、現行の決着後の流れ（集合・総評・試合後の選択画面への戻り等）に合流

### C. 決着演出（時間切れ）
8. 時間切れの瞬間にゲームを停止し、画面中央に「時間切れ」を表示
9. 「時間切れ」を消して、勝った組を 6 と同じ形式で表示。引き分けは「DRAW」（仮）
10. その後、現行の流れに合流

### D. 決着演出の共通
11. 演出の各段（スロー時間・カメラ移動・爆発・立ち絵・WIN表示・時間切れ表示）の秒数は定数1か所
12. 陣営サイドで左右を決める既存ルールに合わせる（立ち絵の配置など）
13. 演出中はキルログ・HUD・ミニマップ・ボタン等の情報表示をすべて消す。出すのは演出と実況（音声・字幕）だけ

### E. 実況（決着）
14. 演出の段に合わせて実況する：大将撃破→（大将の爆発で）大将撃破の実況→（止めのキャラ）止めを刺したキャラの実況→（WIN表示）勝った組の実況／時間切れ→「時間切れ」の実況→勝った組の実況。その後は現行の総評→活躍キャラ→締めに合流
15. 足りないセリフはAIで台本に追加（既存の end_boss / end_time / end_draw は流用・分割してよい）。台本ファイル・commentary_lines.md の仕様と矛盾する箇所はこの書類を優先し、リポジトリ内の台本も更新
16. 新しい部品の音声は既存手順（`npm run cm:audio`）で生成。vvproj再生成で既存の調声を消さない。調声は本人が後でやるので待たない

### F. 実況（スロットのリーチ）
17. スロットのリーチは雑談より優先度を下げる。待ち行列で雑談・盤面コメントと競ったら雑談を先に言う
18. リーチは「雑談を1回言って雑談カテゴリがクールタイム中、かつほかに言うことがない」ときだけ言う
19. 言う前にリールが止まって結果が確定していたらリーチは捨てる

### G. バランス
20. POWER_MULT を現行の0.7倍にする（レベル4を現行のレベル3＝1.4に合わせ、他も同率で下げる：[0.49, 0.7, 0.98, 1.4]）。オーラの大きさなど見た目のレベル表現は変えない
21. レベル3・4は基本的に連チャン限定にする（値は試用、定数）
    - コバコの荷物の抽選 POWER_WEIGHTS のレベル3を0に（レベル4は0のまま）：[30, 40, 0, 0]
    - スロットの連チャン確率：レベル3へ SLOT.chain 0.5→0.35、レベル4へ SLOT.chainBreak 0.25→0.15
22. きりたん（値は試用）
    - 包丁は変えない
    - きりたん砲：range 260→310、dmg 0.7→0.85
    - 全弾斉射：range 260→310、dmg 5→7.5（火力1.5倍）
23. めたんのドリル：dur 3→2.4（2割減）
24. コバコの徳：COURIER_DROP.n 3→2（1部屋ごとに1減）。cap は据え置き

### 検証
25. スクショ（PC・スマホ幅）：選択バーの継ぎ目（右端→左端・左端→右端）／大将撃破の爆発・止めの立ち絵と名前・ORANGE/GREEN TEAM WIN／時間切れ表示→WIN表示／演出後に現行の流れへ合流
26. Bot戦の実況ログで、決着の実況が演出の段の順に並ぶこと、リーチが雑談の直後のクールタイム中にだけ出ていることを確認して報告
27. 単体テスト：POWER_MULT・POWER_WEIGHTS・連チャン確率・きりたん・めたん・コバコの値が仕様どおり
28. Bot戦3試合の時間・決着内訳を報告（変更前の直近値と並べる）
29. 既存の単体テスト・verify が通る（仕様変更で期待値が変わる箇所は更新してよい）。e2eテストの追加はしない
30. 公開URLが変わらず、新しい版が反映されている

## 不明なら止めて聞く
- 同時に両大将が倒れる等、勝者が決まらない大将撃破
- サーバー側のスローが既存の時間処理（スロット・反省・ウルト残り時間等）と大きくぶつかる場合
- ループ化で既存の選択操作・15秒猶予の処理に大きな改修が要る場合
