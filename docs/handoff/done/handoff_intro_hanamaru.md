# Code引き継ぎ：開幕演出・花丸改修
対象：~/kiritan_zunda_proto
前提：handoff_map_lanes.md の後に実施（開始部屋が dining 11/12 になっている）

## A. 開幕演出
既存の開幕（phase intro/countdown：横並び万歳→味方カットイン→3,2,1→GAME START）を新演出に置き換える。
既存の開幕は削除せず保存する（別関数・別ファイルに退避し、定数1つで切り替え可能にする）。

### 成功基準
1. 試合開始時、入力ロック状態でカメラが順に映す
   a. 敵大将＋頭上「↓やっつけろ！」
   b. 味方大将＋頭上「↓まもれ！」
   c. 散らかったマップの一角＋画面中央「徳を積め！」
   d. 味方全員を収める＋「なかよくしろ！」
   e. 「準備してね」→3,2,1,0→自キャラ追従・入力解禁
2. カメラ移動はパン（カット切替なし）
3. 各カットの秒数は定数ファイルに置く（既存 INTRO_SPEED の倍率は流用可）
4. サーバー・クライアント同期（カウントはサーバー基準、0で試合タイマー開始）
5. 定数を切り替えると旧開幕が従来どおり動く
6. 既存Bot対戦が最後まで動く。e2eSkipIntro が新演出でも効く

## B. 花丸改修
### 成功基準
1. パッシブ：壁へ約0.2秒押し込み続けると、その壁を破壊。クールダウンなし。触れた瞬間では壊れない。押し込み時間は定数
2. 既存の壁破壊パンチを「巨大拳飛ばし」に置換
   - 前方へ直進。キャラ命中でダメージ、壁命中で破壊
   - キャラも壁も貫通する。同じキャラには1回だけ当たる
   - 一定距離飛ぶか、マップ最外周の壁に当たると消滅
   - 見た目：半透明の巨大な拳（参考：石破天驚拳エフェクト）。チームカラー着色
3. 拳のサイズ・速度・ダメージ・射程・CTは定数ファイル
4. 命中・破壊判定はサーバー側
5. 破壊した壁は当たり判定・視界遮蔽（レイキャスト）・ミニマップに反映
6. 既存Bot対戦が最後まで動く

### 不明なら止めて聞く
- 壁破壊がマップ当たり判定・視界レイキャストの構造と合わない場合

## 禁止
範囲外の変更、他キャラの変更、不要な抽象化
