# Code引き継ぎ：pwfx2（パワーアップ中の余白のエフェクトを消す）

2026-11-26 Chat作成。対象：~/kiritan_zunda_proto。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。

## 仕様（本人）
- pwfx1（docs/handoff/done/handoff_pwfx1.md、live-20261126-2）で入れた「自キャラのパワーアップ中、立ち絵側の余白（#side）の立ち絵の上に重ねるエフェクト（光・オーラなど）」が AI 臭いので、いったん消す。後で別の見た目に差し替える予定
- 消すのはそのエフェクトだけ。立ち絵の表示、反対側の余白の「素材待ち」の枠、パワーアップの状態・表記・実況はそのまま

## やること
- エフェクトの表示を止め、そのエフェクト専用のコード・CSS・画像（あれば）を消す
- 差し替え時に使う「パワーアップ中かどうか・強さ 1〜MAX を余白側へ伝える仕組み」は、エフェクト以外にも使っていれば残す。エフェクト専用なら消してよい。どちらにしたかを報告

## 成功基準
- パワーアップ1と MAX の間、852×393 DPR3 と 1600×900 で、立ち絵 右/左それぞれ、余白にエフェクトが出ていないスクショ。立ち絵は通常時と同じに出ている
- typecheck・test:server・e2e（全体1回）が通る。e2e は増やさない

## 禁止
範囲外の変更、不要な抽象化、素材の加工、e2e の追加、公開サーバーの停止
