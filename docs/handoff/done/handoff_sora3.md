# 引き継ぎ書: sora3（そらのチャージを技ボタンのゲージと％で見せる）

対象: ~/kiritan_zunda_proto（開発側）。公開側への反映はしない（本人の指示でまとめて tools/deploy.sh）。
並列作業ルールは CLAUDE.md に従う。

## 目的
そらのソーラーキャノンのチャージがどこまで溜まっているかを、本人に分かりやすくする。威力・射程・爆風などの性能は変えない。

## 表示
- 技ボタン自体をゲージにする（ボタンの中が下から、または外周が溜まる形。見た目の形は Code に任せ、スクショで報告）
- ボタンに％を数字で出す
- 本人の画面だけ。敵・味方には出さない（今の光の演出は今のまま）
- PC・スマホで同じ表示（技ボタンは共通）

## ％の決め方
基準: 30秒の総ダメージ（keys の第2列、現行 80）を 100% とする。
- 0〜5秒: 0% から「5秒の％」まで秒数に比例して均等に増やす
- 5秒以降: ％ ＝ その時点の総ダメージ ÷ 30秒の総ダメージ × 100（威力と表記を一致させる）
  - 総ダメージは実際の威力の計算と同じ補間で keys から出す（％と威力がずれないこと）
  - 30秒より後も同じ式で100%を超える。4分30秒以降の威力の跳ね上がりに合わせて数値も跳ね上がる
- 数値は整数に丸めて表示
- 発射・撤退でチャージが0に戻ったら、表示も0%に戻る

現行の keys（[5,29] [10,45] [30,80] [270,110] [294,250]、線形補間の場合）での期待値:

| チャージ | ％ |
|---|---|
| 0秒 | 0% |
| 2.5秒 | 18% |
| 5秒 | 36% |
| 10秒 | 56% |
| 20秒 | 78% |
| 30秒 | 100% |
| 4分30秒 | 138% |
| 4分54秒 | 313% |

- 端数の丸め方（四捨五入）で1%ずれるのは可。補間が線形でなければ、実際の補間での値を期待値にする
- 期待値は keys を直接書き写さず、keys から計算してテストする（keys を調整しても追従すること）

## クールタイム中
- チャージは CT 中も進むので、CT 中もゲージと％は更新し続ける
- CT の表示（今の技ボタンの CT 表示）と重なっても両方読めるようにする。重ね方は Code に任せ、スクショで報告

## 成功基準
- ％の計算がサーバーの威力の計算と同じ keys・同じ補間から出ていて、テストで上の表と発射後・撤退後の0%を確認
- ブラウザのスクショ: チャージ途中（30秒未満）、100%超え、CT 中の3枚
- 敵・味方の画面にゲージ・％が出ないことを確認
- npm run typecheck・test:server が通る。golden が変わったら理由を報告して止まれ（表示だけの変更なので変わらないはず）
