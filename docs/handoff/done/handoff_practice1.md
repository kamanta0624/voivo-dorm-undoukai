# Code引き継ぎ：練習モード（キャラ調整の確認用）
対象：~/kiritan_zunda_proto

## 公開サーバーを落とさない
公開側（~/kiritan_zunda_proto_live）への反映は本人の指示でまとめて行う。この作業では反映しない。cloudflared・launchd は触らない

## ゴール
キャラ・技を調整したら、ここで自分 vs 相手1体を好きな条件で即試せる

## 仕様
1. 入口：タイトルに「練習」ボタン。押すたびに本人専用の部屋を作って入る（他人は入れない）。公開版にも出すが、部屋一覧・満員判定・/status の部屋数には含めない。同時に存在できる練習部屋の数は config に上限を置く（仮置き）
2. 選択画面：自キャラを選んだ後、同じ選択バーで相手キャラを選ぶ2段選択。選択猶予カウント・他人待ちはなし
3. 試合：自分1 vs 相手1（Bot）。時間無制限。スロットは止める（回らない・当たらない）。撃破されたら反省なしで即復活（自分・相手とも）
4. 出す物：大将は両陣営とも残す。HPは減るが倒れない（1で止まる）。コバコ・徳アイテム・回復・実況は出さない
5. 練習パネル（試合中、PC・スマホ両対応、ゲーム画面の邪魔にならない位置で開閉式）
   - 相手キャラの差し替え（いつでも。差し替えたらその場で入れ替え）
   - 相手の動き：棒立ち／攻撃なしBot（移動はBotどおり、通常攻撃・技なし）／通常Bot をいつでも切替
   - パワーアップのレベル上げ・下げ（なし〜上限はゲーム本体と同じ）：自分・相手それぞれ
   - アシスト召喚：キャラとレベルを選んで、自陣営・敵陣営どちらにも好きな時に
   - 大将の全快
   - 戻る：選択画面へ（部屋は作り直さなくてよい）
6. 既存の e2e 用フック（E2E_HOOKS、noAuto、e2eAssist 等）に使える処理があれば流用してよい。ただし E2E_HOOKS なしで動くこと

## 成功基準
- 別ポートで：タイトル→練習→自キャラ・相手選択→試合→パネルの全操作→戻る→選択し直し→再開、が通る。PC・スマホのスクショ
- 練習中に別タブから通常の部屋一覧を見ても練習部屋が出ず、通常の部屋に影響しない
- 通常の試合の挙動は変わらない
- typecheck・test:server が通る。e2e は増やさない

## 不明なら止めて聞く
- 選択画面からタイトルへ戻る手段が今ないなら、足すかどうか
- 1 vs 1 で成り立たない既存処理（陣営の人数前提、Bot 補充、決着処理など）に当たった場合

## 禁止
範囲外の変更、不要な抽象化、素材の加工、e2e の追加、公開サーバーの停止・反映、cloudflared の変更
