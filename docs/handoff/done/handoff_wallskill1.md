# 引き継ぎ書: wallskill1（花丸パンチ・アルの突撃を、壊せない壁の近くの狭い場所でも撃てるようにする）

対象: ~/kiritan_zunda_proto（開発側）。公開側への反映はしない（本人の指示でまとめて tools/deploy.sh）。
作業ツリーには別作業（maptile）の未コミットの変更がある。触らず、今回の変更だけをコミットする。

## 症状と原因（Chat の調査、HEAD 22775e9 時点）
- 犬走り（corrTop、高さ5タイル＝80px）のように、壊せない壁（外周 PERIMETER）に挟まれた狭い場所で、花丸パンチとアルの突撃が撃てない
- 花丸パンチ（skills/hanamaru.ts updateFist）: 拳の円（半径 H.r×レベルの size）が外周のタイルに少しでも触れると gone で消える。狭い場所では発射直後に消える
- アルの突撃（skills/aru.ts dashStep）: 判定の形（len 160・w 126）が外周のタイルに少しでも触れると stop で突撃が終わる。幅126px＞廊下80pxなので最初の tick で止まる

## 方針
技の範囲（壁を壊す範囲・敵に当たる範囲）と、止まる判定を分ける。

### 共通
- 壊せない壁の判定を1つの関数にまとめ、拳・突撃の両方から使う。今は外周（PERIMETER）だけ。maptile 側で壊せない壁の種類（透過壁など）が増えたときに、この関数を直せば済む形にする（maptile 側の未コミットの変更は触らない。増えた種類への対応は maptile 側の作業で行う）
- 範囲内の壊せる壁は今までどおり壊す（徳の加算も今のまま）。壊せない壁は壊さずに無視する

### 花丸パンチ
- 拳は「芯」が壊せない壁に触れたときだけ消える。芯の半径はタメなしの拳の半径の半分（H.r / 2 = 15px）。タメのレベルで芯の大きさは変えない
- 円の外側が壊せない壁に触れているだけなら飛び続ける（壁に沿ってある程度平行に飛ぶのは許容）
- 外周に正面から撃った場合も同じ扱い（芯が触れたら消える）
- 芯の半径は数値として chars.ts の hanamaru.skill に置く（名前は Code に任せる）

### アルの突撃
- 範囲が壊せない壁に触れても突撃は止めない
- アル本人の体（PLAYER_RADIUS）の移動は今の moveBody で壁に当たる。進行方向の成分が壁に止められたら、壁に沿って横に滑りながら続ける（突撃の時間 dur が切れるまで）
- 外周に正面から突っ込んだ場合も同じ扱い。滑る方向がない（ほぼ真正面でぶつかった）ときは、その場で止まって dur まで待つか、止めるかを実装前に Code が判断せず質問する

## 成功基準
- verify にテストを追加して通る:
  - 犬走りと同じ高さ80pxの、外周に挟まれた通路で、花丸パンチ（タメなし・最大タメの両方）が通路に沿って射程いっぱいまで飛ぶ。通路の先にいる敵に当たる
  - 同じ通路で、アルの突撃が通路に沿って進み、通路の先の敵に当たる
  - 外周に向けて正面から撃った拳は、芯が外周に触れた位置で消える（それより手前では消えない）
  - 壁に斜めに当たった突撃は、壁に沿って滑って進む
  - 範囲内の壊せる壁は今までどおり壊れる。壊せない壁は壊れない
  - 広い場所（壁から離れた所）での拳・突撃の挙動は変わらない
- npm run typecheck・test:server が通る
- Bot 同士の試合結果（golden）が変わったら、要約を報告してから更新する
