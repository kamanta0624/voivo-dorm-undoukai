# Code引き継ぎ：botai1（Bot の強さ3段階とチームのマクロ、戦略とフィジカルの効き方を調べる）

2026-11-26 Chat作成。botsim1 の後に実行（botsim1 の自動 Bot 戦とログを使う）。対象：~/kiritan_zunda_proto。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。

## 目的（本人）
今の Bot は汎用の1種類。これを
- フィジカル（操作の上手さ）で強・中・弱の3段階
- チームのマクロ（全体の動き方）で数種類
に分け、Bot 戦を回して「戦略とフィジカルが勝敗にどれくらい影響するか」を確かめる。

## フィジカル（1人ごと、3段階）
- 今の Bot を「中」とする（中は今と同じ動きのまま変えない）
- 強・弱は数値の差だけで作る。候補：狙いのずれ（BOT_AIM 周り）、反応の遅れ、技の回避の判断、技・ウルトを使う判断の速さ、低HP時の引き際。何をどれだけ変えたか表にする
- 壁抜け・視界外の情報を使うなど、人間ができないことで強くしない

## マクロ（チームごと）
- 今のチームの動き（gather／raid の割り振り等）を「標準」とする
- 候補を3〜4種類作る。例：大将へ早く寄せる、徳・荷物を優先して稼ぐ、自陣を守って反撃、2人ずつに分かれて攻める、人数有利の時だけ攻める。どれにするかは Code が調べて決め、理由を報告
- マクロはチーム単位で切り替えられるように（1人ずつの Bot の判断の上に乗せる。フィジカルとは独立に組み合わせられる）

## 調べ方
- botsim1 の仕組みで、組み合わせ（フィジカル × マクロ）を両チームに割り当てて回す。同じ組み合わせは陣営を入れ替えて同数回す
- 最低限見たい比較：
  - 同じマクロで フィジカル強 vs 弱、強 vs 中
  - 同じフィジカル（中）で マクロ同士の総当たり
  - フィジカル弱＋良いマクロ vs フィジカル強＋標準マクロ（戦略でフィジカル差をどこまで埋められるか）
- 勝率に幅（95%区間など）を付ける。差が幅に埋もれる場合は「差が分からない」と書き、必要な試合数の目安を出す
- 試合数・回す時間は botsim1 の「誰もいない時だけ」の範囲で。足りなければ途中経過で報告してよい

## 報告（docs/ に md 1本と、botsim1 の HTML に比較の表・グラフを足す）
- 各フィジカル・マクロの中身
- 組み合わせごとの勝率と試合数、決着の種類、キャラ別の成績の違い
- 「フィジカル差1段階」と「マクロの違い」で勝率がどれくらい動くか、の要約
- 気付いたこと（強すぎる・弱すぎるマクロ、マクロで有利不利が大きく変わるキャラなど）。ゲームの数値の調整案は書いてよいが、実際の数値は変えない

## 本番の Bot
- 公開サーバー・練習の Bot は「中・標準」のまま。強さやマクロを本番で使うかは本人が報告を見て決める

## 成功基準
