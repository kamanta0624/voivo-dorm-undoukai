# Code引き継ぎ：font1（戦闘画面の文字を大きくする）

2026-11-26 Chat作成。対象：~/kiritan_zunda_proto。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。

## 目的（本人）
戦闘画面の文字が全体に小さく読みづらい。まず文字を全部少しずつ大きくする。徳・悪行を文字の説明からゲージ表示へ寄せる件は**次の引き継ぎ書**で行う。今回は触らない。

## 仕様（本人決定）
- 対象：試合中の画面の文字すべて（HUD・キルログ・ポップ・ラベル・スロット周り・ミニマップとボタン・決着演出・カットイン・実況字幕・Phaser のテキスト）
- 対象外：タイトル、キャラ選択・待機画面（#lobby）、ルール説明、slot.html（スロット単体）、チュートリアル。境目が曖昧なものは最初に一覧で報告（止めずに進める）
- 一律 +20%：CONFIG に UI_FONT_SCALE（1.2）を1か所置き、対象のすべての文字サイズに掛ける。個別の数値の書き換えは増やさない（既存の ${C.HUD_SCALE} のように CSS を作る所で係数を入れる形が参考。方式は Code 案）
- 下限：拡大後も論理サイズ 8px 未満になる文字は 8px に引き上げる（CONFIG に UI_FONT_MIN、8）。タッチ用の max(11px, …) のような物理 px の下限は維持
- HUD_SCALE（スロット・顔パネルの倍率 1.2）は変えない。HUD_SCALE の zoom の中の文字にも UI_FONT_SCALE は掛ける（最終 1.44 倍になる）。溢れる場合は止めて聞く
- 文字が大きくなって溢れる・重なる・見切れる箇所は、枠・余白を最小限だけ直す。大きなレイアウト変更が要る箇所は止めて聞く

## 成功基準
- 前後のスクショ（PC 幅・スマホ幅。試合中、スロット演出中、決着演出中、キルログが埋まった時）
- 変更した文字の一覧表（セレクタまたは場所・旧サイズ・新サイズ）。下限で引き上げたものに印
- 溢れ・重なり・見切れが無い（上のスクショで確認、あれば報告）
- typecheck・test:server・e2e（全体1回）が通る。e2e は増やさない。UI の座標に依存して壊れる e2e があれば報告

## 不明なら止めて聞く
- 二重の拡大（HUD_SCALE × UI_FONT_SCALE）で枠が大きく崩れる場合
- 対象か対象外か判断できない画面

## 禁止
範囲外の変更、不要な抽象化、e2e の追加、公開サーバーの停止、ゲームのルール・数値の変更、徳・悪行表示のゲージ化（次の引き継ぎ書）
