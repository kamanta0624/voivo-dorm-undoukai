## 1. スロット：新クラシック
### 抽選・払い出し（クラシックのまま）
- 当否・罰の確率は slotRate・penaltyRate（徳で決まる）、当選時 徳 winToku、連チャン chain・chainBreak、tier は連チャンごとに1段上がる、gap・penHold もそのまま
- 払い出しはクラシックどおり、パワーアップかアシストのどちらか1つ（SLOT.payout の抽選）
- 罰はクラシックどおり、ダメージ・減速・攻撃ダウンから1つを抽選（生存者のみ、dur 8秒）
- コバコ撃破はクラシックどおり（荷物を落とす）。モダンの「高確率保留」は使わない

### 残すもの（モダンの見た目）
- 保留：常に4つ先読み。保留を積んだ時点の徳で当否を決める（＝クラシックの startSpin の抽選を保留を積む時点へ移す）。1回転ごとに先頭を消化して1つ積む。連チャンの払い出し・罰の表示中は消化を止める
- 保留の色・先バレ・リーチ演出（リーチのみ／ちびキャラ／カットイン／魚群／特別な魚群）・全回転、演出範囲の判定（試合の視界・キルログ域）
- リーチ：2つ目がそろったらリーチ、3つ目の停止を演出の秒数（最大3秒）だけ遅らせる
- リールは9絵柄（試合の編成から）。見た目だけで、そろった絵柄と払い出しの強さは連動させない
- 当選の音＋画面中央のお知らせ（slot3）は残す。「→攻め時！？」はフィーバーがないので出さない
- 信頼度の目安は徳5でモダンと同じ（リーチ10%・先バレ40%など）になるよう、外れ側の選択率をクラシックの当選率で引き直す。徳が上がるほど信頼度が上がる性質は保つ
- 実況は既存のクラシックの実況（cm.slot・cm.penalty）＋リーチ等の既存部品
