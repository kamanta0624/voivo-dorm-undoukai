# Code引き継ぎ：nia1（実況に琴詠ニアを追加、No.7 と選択式）

2026-11-26 Chat作成。対象：~/kiritan_zunda_proto。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。

## 仕様（本人）
- 実況に VOICEVOX の琴詠ニア（ことよみにあ）を追加する。No.7 と琴詠ニアのどちらで聞くかをプレイヤーが選ぶ（選択式）。No.7 はそのまま残す
- 台本は琴詠ニア用に新しく書き下ろし：docs/handoff/nia_lines.json（Chat 作。キーと部品の書き方は src/shared/commentary_script.json の lines と同じ。口調はアナウンサー風の丁寧語）。本人が直す前提
- 部品（キャラ名・技名・場所など parts）は No.7 と同じ読みを琴詠ニアの声で作る
- 雑談（docs/commentary_chatter.md）は文面を変えず琴詠ニアの声でも作る（Chat の判断。本人が別の文面にしたければ後で差し替え）

## やること
1. 台本の置き場所：nia_lines.json を src/shared/ 配下へ置き、今の台本の読み込み・npm run cm:vvproj・cm:audio・cm.json の作りに、実況者ごとの台本・styleId・音声の出力先を足す。No.7 の台本・音声ファイルは中身を変えない
2. styleId：VOICEVOX エンジンの /speakers から琴詠ニアのノーマルの id を取って入れる（推測で書かない）
3. 音声：琴詠ニアの vvproj を作り、調声前の音声のまま cm:audio で出す（調声は本人が後でやる。No.7 と同じ流れ）
4. 選択：選択画面の「立ち絵 右/左」と同じ並び・同じ作りで「実況 No.7／琴詠ニア」を置く。端末に保存して次回も同じ。既定は No.7。観戦でも効く
5. 実況の再生がクライアント側で選べない作り（サーバー側で1本の音声を決めている等）だった場合は、作り方の案を出して止める
6. 字幕・ログに実況者名が出る箇所があれば、選んだ実況者の名前にする
7. クレジットに「VOICEVOX:琴詠ニア」を足す。琴詠ニアの利用規約（VOICEVOX 公式の琴詠ニアのページから辿る）を読み、表記の決まり・商用可否・禁止事項を要約して報告。読めない・本作の使い方が禁止に当たりそうなら止める
8. public/rules.html の実況の記載（フッター「実況：VOICEVOX:No.7」など）に琴詠ニアを足す

## 成功基準
- 実況を琴詠ニアにして1試合（Bot で可）流し、開始前（pre_match）・撃破・スロット当選・決着・締め（close）が琴詠ニアの声で鳴る。No.7 に戻すと今までどおり
- nia_lines.json のキーが No.7 の lines と過不足なく一致（足りない・余るキーは一覧で報告。勝手に埋めない）
- 同じ端末で選択がリロード後も残る
- typecheck・test:server・e2e（全体1回）が通る。e2e は増やさない

## 不明なら止めて聞く

- 音声ファイルが大きく増えて読み込みが重くなる場合（選んだ実況者の分だけ読む形にできないとき）

## 禁止
範囲外の変更、不要な抽象化、No.7 の台本・音声の変更、e2e の追加、公開サーバーの停止
