# 引き継ぎ書: itako2（イタコの狐火の追尾を短くする）

対象: ~/kiritan_zunda_proto（開発側）。公開側への反映はしない（本人の指示でまとめて tools/deploy.sh）。
作業ツリーには別作業（maptile）の未コミットの変更がある。触らず、今回の変更だけをコミットする。

## 目的
狐火を飛ばして逃げる戦法をなくす。追尾中の狐火はイタコの近くでしか働かないようにする。

## 変更（chars.ts の itako.skill と skills/itako.ts）
- 再発動で標的を選ぶ範囲 range: 260 → 180px
- 追尾中（mode 'home'）の火の玉は、次のどれかで消える（命中・壁・寿命は今のまま）
  - 今いるイタコの体の中心から 260px より離れた（発射したときの位置ではなく、毎tickのイタコの位置から測る）。新しい数値 leash: 260
  - 追尾を始めてから 360px 進んでも当たらなかった。新しい数値 homeRange: 360
  - イタコが倒れた（周回中・待機中と同じ扱いにする）
- 寿命 life: 3秒は残す
- 数値の名前（leash・homeRange）は Code に任せてよい。chars.ts の skill に置く
- docs/char_catalog.md と .claude/skills/char の狐火の記載を更新する

## 成功基準
- verify にテストを追加して通る:
  - 標的が 180px（＋相手の半径）より遠いと再発動しても追尾しない。内側なら追尾する
  - 追尾中にイタコが標的と反対へ動き、260px より離れたら消える（命中しない）
  - イタコが動かず、標的が逃げ続けて 360px 進んでも当たらなければ消える
  - 追尾中にイタコが倒れたら消える
  - 近くの標的には今までどおり命中して 15 ダメージ
- npm run typecheck・test:server が通る
- Bot 同士の試合結果（golden）: イタコのいる試合は変わる可能性がある。変わったら要約を報告してから更新する

## やらないこと

- 公開版への反映
