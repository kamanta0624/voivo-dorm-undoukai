# 引き継ぎ書: tune2（自分中心の範囲を体の中心へ・大将の爆弾マーク位置・cm:vvproj の1回実行）

## 1. 自分中心の範囲を「体の中心」基準にそろえる（tune1 調査の案B）
- 現状: 自分中心の範囲技は、判定もエフェクトの円の中心もキャラの足元。ドットは足元から上へ描くので、円が体の中心より約15px手前に出て見える
- 変更: 自分中心の範囲判定と、その輪のエフェクトの中心を、どちらも体の中心（足元から上へ。ずれ量はドットの描画から決め、定数1か所）にする。見た目と判定を一致させる
- 対象: あいえるたんの加速と、tune1 調査で挙がった「自分中心に描くエフェクト」を持つ技・処理（小夜の舞の輪、もち子の発射の輪、アシスト呼び出し・回復・ウルト・罰の輪、ひまりの鎌の扇 など）。ほかに自分中心の範囲判定があれば洗い出して同じ扱いにする
- 対象外: 移動・壁の当たり、弾の当たり、通常攻撃の射程、アイテム取得判定（縦長長方形）、リコールの跡など位置を示すだけの演出、ビィの残像。これらに手を入れる必要があると判断したら実装前に報告
- 移動中に円が発動位置に残る（置き去り）のは今回は直さない
- 成功基準: 静止状態で加速の円の中心が体の中心と一致（計測で0px±2）。円の縁ちょうどの味方で判定と見た目が一致。変更した技・処理の一覧を報告。verify・golden の変化は理由付きで報告

## 2. ビィの爆発カウントダウン: 大将の爆弾マークの位置
- 現状: 大将では以前の目印と同じ高さに出て、顔に重なる（verify/evidence/tune1/bii_count_500.png）
- 変更: 大将のときはマークを顔に重ならない高さまで上へずらす。プレイヤーキャラの位置は変えない
- 成功基準: ブラウザで大将の顔とマークが重ならないスクショ

## 3. cm:vvproj を1回の実行で雑談まで入るように直す
- 現状: 1回目の実行で雑談の JSON を書き出したあと、同じ実行内で古い JSON を読んだままになり、雑談が vvproj に入らない（2回実行が必要）
- 成功基準: 雑談を1本書き換えた状態から cm:vvproj を1回実行して vvproj に反映される。変更がないとき既存の vvproj 項目（オーバードライブの調声を含む）が変わらない
