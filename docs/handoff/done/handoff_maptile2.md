# handoff_maptile2：マップチップ試験2（壁の正面・11/18の部屋割り当て）

前提：handoff_maptile1 の試験ページ（maptest.html・src/maptest/）。未コミットのまま続ける。コミットしない
範囲：試験ページだけ。map.json・ゲーム処理・e2e・公開版は触らない。素材の扱い・クレジットは maptile1 と同じ

## 1. 壁の正面チップ
- 当たり判定・間取りは1マスのまま。見た目だけ変える
- 壁の正面チップ（BaseChip 52〜77行、2マス高）を、部屋・廊下から見て北側にある横向きの壁に使う。上の1マスを壁のマス、下の1マスを部屋側の床のマスに重ねて描く（部屋の内側へ1マスはみ出す）
- それ以外の壁（縦の壁、部屋の北側に面する壁の裏側など）は今の天井オートタイルのまま
- 正面チップは部屋ごとに選べるよう対応表（chips.ts）に持たせる
- 扉は今の「壁の切れ目」のまま。扉チップは置かない
- はみ出しで床の見え方が不自然になる箇所（狭い前室・廊下の細い所など）があれば一覧で報告。勝手に間取りで逃がさない
