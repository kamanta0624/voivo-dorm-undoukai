# Code引き継ぎ：aarange1（射程の円を遠距離の射程に・きりたん/ずん子の近接AAを一時削除）

2026-11-24 Chat作成。基準コミット 2daaf66。

## 背景
- きりたん・ずん子が近接AA（包丁／パンチ）を持ったため、自キャラ足元の射程の円が近接の射程（50px）になり、遠距離AAがどこまで届くか分からない
- きりたんが暴れているので、試しに近接AAを外して性能を落とす

## やること
1. 射程の円：`src/client/main.ts` 1387行付近 `DEFS[mine.char]?.aa[0].range` を、通常攻撃の最長射程（`src/shared/chars.ts` の `aaRange`）で描く。他に `aa[0]` を射程表示に使っている箇所があれば同様に
2. 近接AAを一時的に外す（`src/shared/chars.ts`）
   - きりたん：`aa` から `{ ...MELEE, name: '包丁', dmg: 1.2 }` を外し、きりたん砲だけにする
   - ずん子：`aa` から `{ ...MELEE, name: 'パンチ', dmg: 0.9, cd: 1.1 }` を外し、遠距離だけにする
   - 一時的な措置なので、外した定義は同じ場所にコメントで残し、戻すときはコメントを外すだけで済むようにする
   - きりたん砲の射程 `range` 310→200（全弾斉射の射程 `skill.range` 310 は変えない）
   - 遠距離モードの `far: 60` は残す（近接を戻したとき用）。近接がない状態で対象が60px以内でも遠距離で撃つこと（`aaMode` のフォールバックで撃てる想定。違ったら直す）
3. 選択画面のステータス棒・説明文で、近接が前提の記述があれば合わせる（棒は自動で1本になる想定）
4. 包丁・パンチ前提のテスト（`verify/server.ts` 315・574〜575・983〜986行付近など）を今の仕様に合わせる。golden のハッシュは更新
5. 更新情報に「きりたん・ずん子の近接攻撃（包丁・パンチ）を試験的に削除」「きりたん砲の射程を短縮」「射程の円を遠距離の射程で表示」を追記

## やらないこと
- きりたん砲の射程以外の数値（射程・威力・CT・移動）の変更
- 実況の雑談「きりたんの頭の包丁は、髪飾りなんです」は髪飾りの話なので触らない
- 公開版への反映（本人の指示でまとめて行う）

## 成功基準
- きりたん・ずん子で出撃すると、足元の円がきりたん砲 200px／ずん子の遠距離 200px で描かれる。他キャラの円は今と同じ
- きりたん・ずん子は敵が隣接していても遠距離AAを撃ち、包丁・パンチを出さない
- `verify/server.ts` 全件OK、golden 更新済み、e2e は関係する項目だけ確認
- 終わったら本ファイルを docs/handoff/done/ へ git mv してコミット
