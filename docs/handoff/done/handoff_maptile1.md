# handoff_maptile1：マップのタイル置き換え試験

## 目的
フリー素材のマップチップで現行マップを描いたときの見た目を確かめる。本体のゲームには組み込まない。

## 素材
/Users/kamatashintarou/MCP_Learning/nimonooki_マップチップ素材基本セット01_
- BaseChip_nimono.png：16×16、8列（屋外・床・壁・家具・小物）
- オートタイル/Auto_*.png：31枚（WOLF RPGエディター形式）
- 規約（https://booth.pm/ja/items/8466514）：加工可。再配布禁止。クレジット表記が必須「煮(https://skima.jp/profile?id=378449)」

## 手順
1. 素材はリポジトリにコピーしない。gitignore対象のローカルパス（例：assets_local/nimono へのシンボリックリンク）から読む
2. 現行マップの間取りデータ（部屋・壁・扉・通路・部屋の割り当て）を読み、タイルで描く単体の試験ページを作る（devサーバー限定、例：/maptest）。間取りデータとゲーム処理は一切変更しない
3. 現行のグリッド・表示倍率とチップ16pxの関係を調べ、整数倍・ニアレストで合わせる。合わない場合は止めて報告
4. 部屋の種類ごとに床・壁のチップを割り当て、対応表を1ファイルにまとめる（座標指定。本人が後で差し替えやすいように）。オートタイルは壁・床の境界に使えるなら使う。合うチップがない部屋は現行の単色のまま残し、一覧で報告
5. 試験ページの隅にクレジットを表示

## 成功基準
- /maptest で現行マップ全体がタイル表示され、壁・扉の位置が現行と一致する（現行描画との切り替えで比較できる）
- 本体（ゲーム・e2e）に差分がなく、素材がgit管理外
- 対応表・合わない部屋の一覧・スクリーンショット（全体と部屋のアップ数枚）を報告

## やらないこと
- 本体への組み込み、公開版への反映、家具・荒廃演出の配置、流用防止処理
