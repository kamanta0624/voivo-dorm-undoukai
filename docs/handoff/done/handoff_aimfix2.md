# Code引き継ぎ：aimfix2（タメが潰れた時の CT・そらの予兆）

2026-11-24 Chat作成。aimfix1 の確認事項への本人の回答。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。

## 1. タメが潰れた時は CT を使わない
- 花丸パンチの溜め（fistWind）・アルのタメ（charge）が、スタンなどの cancel で撃たれずに消えた場合、CT を使わない（技がすぐ使える状態に戻す）
- 花丸はチャージも戻す（溜めに入る前のチャージ秒数のまま。消えた時点で0にしない）
- 撃破で消えた場合は今までどおり（撤退でチャージ0、CT の扱いも今のまま）
- 成功基準：サーバー単体テストで、溜め中・タメ中にスタンを受けると、CT が溜めに入る前の値に戻り（花丸はチャージも同じレベル）、すぐ撃ち直せる

## 2. そらのソーラーキャノン：遅延中の射線の予兆
- 発射から発生までの遅延（delay、約0.35秒）の間、射線を細い線で表示する。敵味方とも見える（視界の判定は今のビームと同じ）
- 長さは発射時の射程、太さはビーム幅より十分細く、点滅または薄く。発生したら消えてビームに替わる
- チャージ4分30秒超の発射（遅延なし）では出さない
- 成功基準：遅延中に敵の画面で線が見える（スクショ）、発生と同時に消える
