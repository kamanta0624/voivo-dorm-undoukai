## 1. ホワイトカル：通常攻撃をクナイ投げに（中距離キャラ）
- 通常攻撃を近接から遠距離（投げたクナイが飛ぶ弾）に変更。射程は今の吹雪の長さ（chars.ts whitecul.skill.len＝200）。値は吹雪を参照せず aa に直接持つ
- 硬直（攻撃時に止まる時間などの手触り）は今の近接 AA と同じ。間隔（cd）は今の近接 AA の1.1倍（今 C.ATTACK_COOLDOWN_MELEE＝1 → 1.1）。威力の倍率は今と同じ
- 弾速は仮置き（ほかの遠距離 AA と比べて報告）。クナイの見た目は簡単な図形でよい（素材なし）。図形は起動時に1回だけ画像にして、弾は Image・Sprite で置く（毎フレーム Graphics で描かない。既存の遠距離 AA の弾の描き方が Graphics なら、それに合わせるかどうかを報告）
- 吹雪・ロール（スピード）・ステータスは変えない。説明文（選択画面・rules.html）に中距離で戦うキャラである旨とクナイを書く。AA 名は「クナイ」
- 実況・キルログで通常攻撃名を出している所があれば追従

## 2. 強さの表記：「レベル」をやめる
- パワーアップの強さ：「パワーアップ1・2・3・MAX」（今のレベル4＝MAX）。スロットで強くなることは「レベルアップ」でなく「パワーアップ2に上がる」などと書く。レベル4以降の「+」の扱いがあれば MAX+ など、今の表記に合わせて提案
- アシストの強さ：星の数「★・★★・★★★・★★★★」
- C.POWER_TIERS（パワーアップとアシストで共用）を、パワーアップ用とアシスト用の2つの表記に分ける
- ゲーム画面：今どのパワーアップか数字でひと目で分かるようにする。自軍・敵軍の一覧のアイコンと、パワーアップ中のキャラの頭上（HPバーの近く）に「1」「2」「3」「MAX」の小さな札。アシストは頭上と一覧に★。配置はスクショを付けて報告
  - 頭上の札は、起動時に「1」「2」「3」「MAX」「★〜★★★★」を1枚のテクスチャ（コマ分け）に作り、Image で置いてコマを切り替える。Phaser の Text を毎回作らない・書き換えない。画面外のキャラの札は描かない
  - 一覧のアイコン（DOM）の札は、強さが変わった時だけ書き換える
- マニュアル（public/rules.html）：パワーアップの説明を新表記に直し、強さごとの簡単な絵を付ける（背後のオーラが1→MAX で大きくなる様子。今の仕様：1は1.2キャラ分程度、MAX は大将と同じ大きさ）。絵は HTML/SVG の単純な図形（人型のシルエットと輪）でよい。キャラの素材は使わない
- 実況：「レベルアップ」のセリフを新表記（パワーアップ2・パワーアップMAX など、アシストは★の数の言い方を提案）に作り直し、実況音声も作り直す（VOICEVOX のプロジェクトを更新し npm run cm:audio。手順は既存の実況音声の作り方に従う）。変えたセリフの一覧を報告
- 実況：チャンスアップの当選は、何回目かで言い方をずらす（数字の連呼にしない）。1回目「さらにパワーアップ」、2回目「パワーアップが止まりません」、3回目（MAX 到達）「ここからは（キャラ名）の時間か」の方向。言い回しの細部・語尾は既存の実況（No.7 のアナウンス調）に合わせて案を出し、名前は既存の定型文＋名前の連結で
- 実況：場所の前置き pre_t1（src/shared/commentary_script.json 120行。今は「[場所]も激しい戦いだ！」「[場所]も熱い！」の2択で、注目の移動のたびに出る）を、短く・候補を多くする（本人）。「熱い」は多すぎるので1つ残すかなくす。場所名＋短い一言（目安：場所名の後ろは5〜6音まで）で6〜8個。案：「[場所]も熱い！」「一方、[場所]！」「[場所]でも！」「[場所]、動いた！」「[場所]はどうだ！」「おっと[場所]！」「[場所]も見逃せない！」。既存のアナウンス調に合わせて調整してよい。同じ候補が続かないようにする仕組みが既にあれば使う。docs/commentary_spec.md・commentary_readings.md も追従。同じ回の実況音声の作り直しに含める
- 練習パネルのパワーアップ・アシストの表示も新表記に

## 3. マニュアルにスロットのスペック表
テストプレイヤーから「何秒に1回転するか」「徳を積むと何が変わるか」が分からないとの声。
- rules.html のスロットの節に表を足す。値は CONFIG.SLOT（今の既定のスロット方式）から取る：1回転の秒数（spin）、徳ごとの当たる確率（rate×rateMult。徳0・5・10などの代表値）、チャンスアップの回数と徳ごとの確率、罰の出る確率と内容、7が出る条件と割合、当たった時の徳の増減
- 「徳を積むと変わること」をスロット以外も含めて箇条書きにする（コードから洗い出す）
- 値は設定から自動で出せるなら自動（ビルド時生成など）、無理なら手書き＋どの設定値かのコメント。どちらにしたか報告
- 表の案はスクショで本人確認してから確定

## 4. 練習モードの UI
### タイトル画面
- 「練習」を、部屋の一覧（.rooms）と同じ並び・同じサイズのボタンにする（部屋の最後に並べる）。色だけ変える（部屋はオレンジのグラデーション。練習は別系統の色、例：青系）。下の段（ルール説明・更新情報・クレジット）からは外す
### 試合中の練習パネル（今は画面上部中央の小さな「練習 ▼」で、スマホでは押せない）
- 閉じている時：画面の左端に縦長のタブ「練習」を出す。幅は指で確実に押せる大きさ（最低 44pt 相当）、高さはその2〜3倍。位置は左上の組アイコン列・バフ欄より下、左下のスティック操作域とかぶらない高さ。PC でも同じ位置
- 開いた時：左端から引き出しが出る。幅は画面横幅の1/4まで。タブは引き出しの右端にくっついたまま残り、押すと閉じる。引き出しの外を触っても閉じない（ゲーム操作と競合させない）
- 引き出しの中は縦1列、上から：
  1. 相手（キャラの選択。今の select のままでよい）
  2. 相手の動き（棒立ち／攻撃なし／通常Bot を縦に並べた大きなボタン。選択中が光る）
  3. パワーアップ 自分（−［表記］＋ を横1行、ボタンは大きく）
  4. パワーアップ 相手（同上）
  5. アシスト（種類の選択・★の選択、その下に［自陣に］［敵陣に］）
  6. ［大将を全快］［選択画面へ］
  入りきらなければ引き出しの中だけ縦スクロール。ボタン・選択の当たり判定は高さ 44pt 相当以上
- 引き出し・タブは DOM。表示内容（パワーアップの表記・選択中の動きなど）は値が変わった時だけ書き換え、要素の参照は一度だけ取る。引き出しの開閉は CSS の transform のアニメーションで行い、filter・blur・box-shadow は付けないか、付けても動かさない
- 開いている間もゲームは止めない。スマホで引き出しが左のスティック操作域を覆う間はそこでスティックは出ない（仕様として許容。報告に書く）
- 見た目はスマホ（iPhone 15 Pro 横向き相当）と PC のスクショを付けて報告。本人が見て調整を指示する
