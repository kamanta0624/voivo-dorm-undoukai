## A. Botのリコール判断（GameRoom.ts botThink）
現状：HPが BOT_RECALL_HP 未満なら敵が近くにいてもリコールを始め、溜め中は止まる。被弾で中断しても次の思考で即リコールし直すため、止まったまま一方的に倒される
1. 「脅威あり」の間はリコールを始めない。溜め中に脅威ありになったら溜めを中断（cancelRecall）
   - 脅威あり＝次のどちらか
     - 現行の foes と同じ判定（自陣営の視界内・BOT_AGGRO_RANGE 以内・hidden でない敵）が1体以上
     - 直近 BOT_RECALL_SAFE 秒以内に被弾した（射程外・視界外からの攻撃対策）。被弾時刻の記録がなければ Player に1項目足す
   - 仮置き：BOT_RECALL_SAFE 1.5秒
2. 低HP（BOT_RECALL_HP 未満）で脅威ありのときは「攻撃」か「逃亡」を選ぶ
   - 攻撃：狙う敵の残りHP ≤ 自分の残りHP（絶対値）なら現行の botFight
   - 逃亡：それ以外。狙う敵から離れる方向で自陣の給湯室（RECALL_ROOMS）へ向かう（既存の経路探索を使う。逃亡専用の新しい経路処理は作らない）。逃亡中も射程内の敵には通常攻撃（現行どおり自動）、技は現行の botSkillUseful に従う
   - 判定の比率は定数（仮置き：敵HP ≤ 自HP × 1.0）
3. 低HPで脅威なしになったら、その場でリコールを始める（給湯室にいれば現行どおり食べる）
4. 毎思考で攻撃⇔逃亡が細かく切り替わらないようにする。仮置き：一度決めたら BOT_FLEE_COMMIT 秒（1秒）は維持
5. アシストの思考（assistThink）は対象外

## B. 撃破後の視界の絞り（自分の視界だけを狭める）
現状：大爆発の後、main.ts の iris（画面全体を黒い円形グラデーションで覆う）で暗転するため、近くの味方の視界まで見えなくなる
6. iris の全画面暗転を廃止する。代わりに、倒されたキャラ自身の視界半径を、大爆発の後〜RESPAWN_BASE までに visionRadius → 0 へ縮める（縮み方は現行の iris と同じ (1−t)^2）
7. 縮む視界は陣営の共有視界の一部として扱う（味方の画面でもその円が縮む）
   - クライアント：霧（fog）のマスクに使う eyes に、絞り中の自陣営キャラを縮めた半径で入れる（main.ts の eyes 2か所。描画の視界判定 1319行付近も同じ半径）
   - サーバー：visibleTo の eyes と players の送信判定（dying）で、絞り中のキャラを縮めた半径で扱う。演出中の敵キャラ自身を相手陣営へ送るのは現行どおり大爆発まで
   - 半径の計算はサーバー・クライアント共通の関数1つ（shared）にする
8. 結果：孤立して倒されたら円が縮み切って霧だけになる。味方が近くにいれば、その味方の視界は見え続ける
9. カメラは絞り切るまで自キャラの位置のまま（現行どおり）。絞り切った後の反省中の表示（視点移動・味方の共有視界）は現行どおり
10. 演出全体の長さ・復活時刻は変えない

## C. アシストの撃破演出
現状：アシストは倒れると即削除（GameRoom.ts 1025行 `if (v.assist) { this.players.delete(v.id); return; }`、dying() も assist を除外）
11. アシストもプレイヤーと同じ撃破演出（揺れ＋小爆発→大爆発で消える）を出す。大爆発の後に削除
    - 爆発の大きさはアシストの表示倍率（DOT_SCALE × ASSIST.scale と DOT_SCALE の比）を掛ける（koBoom の s）
    - 演出中のアシストの視界・敵への送信はプレイヤーと同じ（大爆発まで）。視界の絞り（B）はアシストには不要（大爆発で視界終了）
    - 撃破カットイン・立ち絵・徳の扱いは現行どおり出さない（1011・1018行）
12. 演出中のアシストは「いない」ものとして扱う：攻撃・技・Bot の標的・召喚数の数え方・重複召喚のレベルアップ判定・一覧（roster）のアシスト表示・決着演出の止めのキャラ。players に倒れたアシストが残ることで挙動が変わる箇所を grep で洗い出し、alive を見るよう揃える。洗い出した一覧を報告

## 成功基準
1. 単体テスト（verify/server.ts）に追加：
   - 低HPのBotが、視界内に敵がいる間はリコールを始めない。溜め中に敵が見えたら中断する
   - 低HPのBotが、自分より残りHPの多い敵からは給湯室方向へ離れ、残りHPの少ない敵には攻撃する
