# Code引き継ぎ：ierutan3（アップグレードの発動エフェクトを作り直す）

2026-11-27 Chat作成。対象：~/kiritan_zunda_proto。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。

## 仕様（本人）
- 今の発動エフェクト（自分中心に長方形が広がる。ierutan2）は、誰に効いたか分からないのでやめる
- 発動した時点の範囲（自分の体の中心を中心とする 400×300 の長方形）の位置に、広がらずにその場で出す。範囲の外側（縁）に強く、内側にいくほど弱く（縁から内へ薄れる光）
- 効果の対象になったキャラ（範囲内の味方・アシスト・自分）にも、それぞれエフェクトを出す
- 広がらせない

## やること
- サーバー（src/server/skills/ierutan.ts）：発動時の fx に、効果を受けたキャラの id の一覧を載せる（判定は今の長方形のまま、変えない）
- 画面（src/client/skills/ierutan.ts）：
  - 発動時：範囲の長方形をその場に出す。縁が一番強く、内側へ向かって弱くなる塗り（中心付近はほぼ透明）。表示時間は今の発動エフェクトと同じ程度で、大きさは最初から最後まで変えない（フェードアウトはよい）
  - 対象：fx に載ったキャラそれぞれに、短いエフェクト（例：体を包む光・上へ流れる矢印の強調など。効果中の印 mark とは区別できるもの）を出す。キャラが動いても付いていく
  - 今の「広がる二重の長方形と放射状の線」は消す
- 敵から見えるかは今と同じ（視界内なら見える）

## 成功基準
- 発動の連番スクショ（スマホ 852×393 DPR3）：範囲が広がらずに出て、縁が強く内側が弱い。範囲内の味方とアシストと自分にだけ対象のエフェクトが出て、範囲外の味方には出ない
- 効果の判定（誰に掛かるか）は変わらない（サーバー単体の確認は今のまま通る）
