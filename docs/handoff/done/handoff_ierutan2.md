# Code引き継ぎ：ierutan2（アップグレードの範囲を長方形に、撃破された時の立ち絵を選択画面と同じ衣装に）

2026-11-26 Chat作成。対象：~/kiritan_zunda_proto。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。

## 仕様（本人）
1. アップグレード（あいえるたんの技）の範囲が通常攻撃の射程（150）と重なって分かりづらい。範囲をもっと広い長方形にする
   - 大きさ：横400×縦300（ゲーム内の px。仮置き、プレイで調整）。自分の体の中心が長方形の中心。向きは画面に対して固定（キャラの向きで回さない）
2. あいえるたんの撃破された時（koed）の立ち絵が、選択画面と服が違う（今の「なき」は衣装違い）。選択画面と同じ衣装の「恐怖」に替える

## やること
### 1. 範囲を長方形に
- src/shared/chars.ts の ierutan.skill の `r: 150` を、横幅・縦幅の2つの値に置き換える（名前は Code が決める）
- サーバー（src/server/skills/ierutan.ts）：対象の判定を「体の中心どうしの距離 ≤ r」から「横の差 ≤ 横幅/2 かつ 縦の差 ≤ 縦幅/2」に
- 画面（src/client/skills/ierutan.ts）：
  - 技が使える間に本人の画面に出す範囲を、円から長方形に（塗りと枠の濃さは今の円と同じ）
  - 範囲内の味方の頭上の▼も、同じ長方形で判定する
  - 発動時の演出（広がる二重の輪と放射状の線）は、長方形が広がる形にする。凝らなくてよい
- fxAtBody に渡している `r` は、長方形の大きさが渡るように直す
- Bot が技を使う判断（botUse）は変えない
- 説明文・ルール説明・キャラ一覧（docs/char_catalog.md）に「半径」「まわり」など円の範囲を前提にした書き方があれば合わせて直し、一覧で報告

### 2. 撃破された時の立ち絵
- src/shared/chars.json の ierutan の `koed` を「恐怖」に（ファイル名は Moiky 素材のフォルダで確かめる）。tools/import_tachie.py で取り込み直す
- 使う場所は今の koed と同じ（撃破されたカットインなど）。他は変えない
- QUEUE の react1 は、react0 の時点の「あいえるたんの koed は衣装違い」という前提で書いてある。react1 の時は、koed が「恐怖」に替わったものとして扱う（本ファイルの完了時に react1 の該当行へ一言書き足す）

## 成功基準
- 練習モードのスクショ（スマホ 852×393 DPR3・PC 1920×1080）で、技の範囲（長方形）と射程の円の見分けがつく
- 長方形の角の近く（例：横190・縦140）にいる味方には掛かり、外（横210）にいる味方には掛からない。サーバー単体の確認でよい
- 撃破された時のカットインで、あいえるたんが選択画面と同じ服で出る（スクショ）
- 他のキャラの数値・挙動は変わらない。golden は、あいえるたんのいる試合だけ変わることを確かめてから作り直してコミット
- typecheck・test:server・e2e（全体1回）が通る。e2e は増やさない

## 禁止
範囲外の変更、不要な抽象化、e2e の追加、公開サーバーの停止、素材の加工
