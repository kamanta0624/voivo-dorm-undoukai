## 1. 技の矢印照準（対象：アル突撃・WhiteCUL吹雪・そらソーラーキャノン・ユーレイちゃんジャッジメント・ずん子ずんだアロー・花丸パンチ）
花丸パンチは5章の自動チャージ化とあわせて対象に入れる。
対象外：めたんドリル、向きのない技（きりたん・小夜・ビィ・あいえるたん・イタコ・もち子・ひまり）。今の挙動を変えない。

### 操作
- 押した瞬間：自キャラから射線の矢印を出す（自分の画面だけ）。初期の向きは今の自動照準（skillAim）の向き
- 押している間：矢印が追従し、移動は継続できる
  - PC：R キー・技ボタン・フィールド上の右クリック、いずれの押しっぱなしでもよい。向き＝自キャラ→マウスカーソル（ワールド座標）。ミニマップ上の右クリック長押し（視点移動）は今のまま
  - スマホ：技ボタンをタップした指を離さずに動かすと、押した位置からのドラッグ方向に矢印が追従。動かさなければ自動照準の向き
- 離した瞬間：向きと発動が確定、サーバーへ向きを送って発射（今の「押した瞬間に発射」をやめる）
- CT中・使用不可時は矢印を出さない

### アル突撃の追加
- 離して確定 → 今のタメ（windup 0.8秒）に入る。タメ中に再度タップ／ドラッグ（PCは技入力の押し直し＋カーソル）で、突撃開始まで向きを変えられる。突撃開始時点の向きで確定
- 突撃中に移動入力で横へ少し動ける既存の挙動（side）は継続
- use() の「移動入力 → 照準 → 向いている方向」の優先順位は、矢印の向きに置き換え

### Bot
- Bot は今の自動照準のまま

### 成功基準
- 上記6技すべてで、PC（R・技ボタン・右クリック）とスマホ（タップ＋ドラッグ）の両方で、離した時の矢印の向きに技が出る
- 照準中に WASD／スティックで移動できる
- アルのタメ中に向きを変えると、変えた向きへ突撃する
- めたん・向きのない技、ミニマップ視点移動に変化がない
- 既存 e2e が通る（変更した操作の e2e があれば合わせて更新）

## 2. そらソーラーキャノンの弾速
現状：発射の瞬間にビームが射程全体へ届く（sora.ts beam() が毎tick 射程いっぱいまで伸ばす）。

- ビームの先端を有限の速度で伸ばすか、発生に遅延を入れるかして、距離200pxへ届くまでの時間を
  `0.25秒（反応時間）＋（S.w/2 ＋ PLAYER_RADIUS）÷ WhiteCULの移動速度` ≒ 0.25 ＋ 18÷187 ≒ 0.35秒 にする
- 方式（先端速度／発生遅延）は Code が選んでよい。値は chars.ts の sora.skill に置き、上の式から導いたことをコメントに残す
- 照射秒・ダメージ・爆発・壁破壊の仕様は変えない（伸びている途中の扱いだけ自然に合わせる）

- 例外：チャージ4分30秒（keys の 270 秒）を超えた発射は今の挙動（発射時点で終端まで届く）のままでよい

成功基準：チャージ4分30秒以下では、距離200で発射を見てから射線と垂直に動いた WhiteCUL がギリギリ当たらない（サーバー単体の検証で確認できればよい）。4分30秒超は今と同じ

## 3. きりたん全弾斉射の弾の射程
- 弾がきりたん本人（その時点の位置）から200px以上離れたらホーミングをやめて直進（既存の orphan と同じ直進）
- 250px以上離れたら消滅
- 寿命 life 3秒・壁で消える挙動は残す。値は chars.ts の kiritan.skill に置く
- ロック射程 range を 310→200（通常攻撃のきりたん砲と同じ）に変更

成功基準：上記の距離で直進化・消滅する

## 4. もち子のファンネル
- 有効射程200：ファンネルがもち子本人（その時点の位置）から200px以上離れたら、次の攻撃を1回した後に消滅
- 値は chars.ts の mochiko.skill に置く

成功基準：200px以上離れたファンネルが次の攻撃の直後に消える。200px未満では今と同じ

## 5. 花丸パンチ
- 押しっぱなしタメをやめ、自動チャージにする。チャージは CT 明けから進み、発射・撤退で0に戻る
- レベルの閾値：Lv1→Lv2 を10秒、Lv2→Lv3 を15秒（＝CT明けから計25秒で Lv3）。chars.ts の lv[].t を合わせて変更
- 火力は全レベル一律×0.8（dmg 倍率 Lv1=1→0.8、Lv2=1.5→1.2、Lv3=2.2→1.76）。サイズ・弾速の倍率は変えない
- 操作は1章の矢印照準（押す→矢印→離して確定）
- 確定後、発射前に溜めを入れる：Lv1 なし、Lv2 0.5秒、Lv3 1秒。溜め中は移動不可・向きは変更可（アルのタメと同じ：再タップ／ドラッグ、PCは押し直し＋カーソル。発射時点の向きで確定）
- チャージ量の表示は今のまま（client/skills/hanamaru.ts の fistCharge：頭上のゲージとレベルの玉）。自動チャージの進行に合わせて出すだけで、見た目は変えない
- パッシブ（壁押し込みで破壊）・Bot の壁破壊（タメなし＝Lv1）は今のまま。Bot は今の botHold に代わり、溜まっているレベルで撃つ

成功基準：CT明けから10秒で Lv2、25秒で Lv3 になり、離した時点のレベル・矢印の向きで、Lv2・Lv3 はそれぞれ0.5秒・1秒の溜めの後に発射される。火力が上記の値になる
