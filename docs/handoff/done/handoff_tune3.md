## 1. イタコの狐火を体の中心へ
- 周回の中心をイタコの体の中心にする
- 玉と相手の当たりも、相手の体の中心で測る（狐火だけ。ほかの弾の当たりは変えない）
- 見た目（玉の描画位置）も判定と一致させる
- 成功基準: 静止したイタコの体の中心と周回の中心のずれが0px（ブラウザ計測）。プレイヤー・2倍サイズ（アシスト・大将）の相手に、見た目どおり当たる（verify）。golden が変わったら理由を報告

## 2. ビィの爆弾マーク: アシストも頭の上へ
- 2倍サイズのアシストにも、大将と同じ式（表示倍率を使った頭の上）でマークを出す。プレイヤーの位置は変えない
- 成功基準: ブラウザでアシストの顔とマークが重ならないスクショ
