# Code引き継ぎ：react1（余白の立ち絵の反応：タップと出来事で表情を変える）

2026-11-26 Chat作成。対象：~/kiritan_zunda_proto。前提は react0 の調査報告（docs/handoff/done/handoff_react0.md、コミット 9f4f956）。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。

## 仕様（本人）
- 対戦中に余白に出ている自キャラの立ち絵が、タップとゲーム内の出来事で表情を変える
- **セリフ（吹き出し）は当面なし。表情の差し替えだけ**
- 出来事と表情：キル→笑う／やられた→悲しむ／残りHPが少ない状態で帰還→ほっとする／出会い頭にやられた→驚く／同じ相手にやられた→怒る／大将に攻撃を当てた→喜ぶ
- タップは頭・顔・上半身・下半身の4部位で反応を分ける
- 合う差分がないキャラ・出来事は**何もしない**（表情を変えない。近い差分での代用もしない）
- react0 で「?」付きだった代用案（WhiteCUL・ひまり・イタコの手を合わせる系、ひまりの説明、ユーレイのゲーム中、ビィの攻撃(ko)など）は**使う**
- 衣装違いの差分は使わない（react0 で除外したもの。花丸「万歳」、小夜「ヨシ・恐怖」、あいえるたん「なき・ウインク・笑い」を含む）。あいえるたんの今の koed（衣装違いの「なき」）は、余白の反応には使わない。撃破カットインでの使い方は変えない
- YMM4用の部品の組み合わせはしない（素材の加工に当たる）

## スマホのタップ（本人の判断：案B）
- 立ち絵が描かれている範囲では仮想スティックを出さない。そこを触ったらタップ扱い
- 立ち絵の範囲の外（余白の残り・ゲーム画面）は今のままスティック
- PC は立ち絵のクリックでタップ扱いにする。マウス位置で照準が向く今の挙動は変えない

## やること
1. **素材**：import_tachie と chars.json に、上の表情差分を足す。キャラごとに「出来事・タップ部位 → 差分ファイル」の割り当てを chars.json に持つ。差分がない所は空にする
2. **横の跳び防止**：余白の中央寄せの幅は、通常の絵で測った値をそのキャラの全差分に使う
3. **タップの部位**：頭・顔・上半身・下半身の境目をキャラごとに chars.json に書く。値は Code が画像を見て仮に決める
4. **タップの割り当て**：どの部位でどの差分を出すかは、react0 の「タップ用に余る差分」と出来事用の差分から Code が案を作る（同じ差分を出来事と兼ねてよい）
5. **サーバーから本人への通知**（react0 の「最小の足し方」どおり）：
   - koed に倒した人の id（kid）を足す
   - 当てた本人へ bossHit。画面側で間引く
   - 帰還成功時に本人へ recalled {帰還前のHP割合}
   - 出会い頭：最初に当てられた時刻を持ち、koed に「倒した相手が交戦開始時に見えていなかったか・何秒で倒されたか」を付ける
6. **出来事の条件**（仮置き。プレイで調整）：
   - ほっとする：帰還前のHPが最大の3割以下
   - 驚く：倒した相手が交戦開始時に見えていなかった、または最初に被弾してから2秒以内に倒された
   - 怒る：この試合で同じ相手（kid）に2回目以降にやられた。条件に合えば「悲しむ」より優先
   - 喜ぶ：大将に当てた時。出すのは5秒に1回まで
7. **表示時間**：差し替えた表情は3秒で通常の絵に戻す（仮置き）。次の出来事やタップが来たら上書きする。数値は config にまとめる

## 止めて聞く
- 3・4（部位の境目とタップの割り当て）は、キャラごとの一覧表と、4部位の線を立ち絵に重ねた画像を作って本人に見せる。本人がOKを出すまでコミットしない
- 割り当てに迷う差分（衣装違いか判断できない等）は、勝手に決めず一覧で聞く

## 成功基準
- 全14キャラについて、出来事・タップごとに出る差分が一覧表と一致する（差分のない所は何も起きない）
- 差分を切り替えても、余白の立ち絵が横に跳ばない
- スマホ（852×393 DPR3）：立ち絵の上を触ると表情が変わり、スティックは出ない。立ち絵の外では今までどおりスティックが出る
- 余白がない画面（1920×1080 全画面）・観戦者・待機中は今と同じで、エラーが出ない
- 新しい通知を足しても、他の人のキャラ・観戦者には届かない（本人宛てだけ）
- typecheck・test:server・e2e（全体1回）が通る。e2e は増やさない

範囲外の変更、不要な抽象化、e2e の追加、公開サーバーの停止、素材の加工、吹き出し・セリフの実装
