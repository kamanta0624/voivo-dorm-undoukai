## 仕様（本人）
- 自キャラがパワーアップしている間、本人の画面にだけ演出を出す。他人の画面・観戦には出さない。解除で消える（残り時間・解除の扱いは今の状態の値に従う）
- 立ち絵側の余白（screen1 の #side。既定は右、選択画面の「立ち絵 右/左」で入れ替え）：今の立ち絵はそのまま、その上にエフェクト（光・オーラなど）を足す。パワーアップの強さ 1〜MAX で強くなる
- 反対側の余白：ちびキャラやスチル。素材はまだないので、差し替え用の枠（素材の置き場所とキーを1か所で定義）と仮表示（枠線と「素材待ち」程度、または非表示）だけ作る。左右入れ替え時は反対側に付いていく
- 余白が無い・狭い画面（PC 16:9 など）：ゲーム画面内の視界の外に控えめに出す（立ち絵は出さない。エフェクトだけでよい）。出し方は案を報告して止めてよい

## 守ること
- ゲーム画面内に出す物は、視界の円・キルログ域・自軍の一覧・HP パネル・バフ欄・ボタン類・ミニマップ・スティックの操作域にかぶせない
- 反対側の余白は将来スロット演出にも使う。スロットの特別演出（画面全体の視界外）と同時に出た時の重なり方を決めて報告（例：パワーアップ側を薄くする、特別演出の間は隠す）
- ゲームの操作を邪魔しない（pointer-events を通す）
- 軽さ優先：
  - 余白の DOM は出す時に1回だけ配置し、動きは CSS の transform・opacity のアニメーションだけ（毎フレーム JS で style を書かない。filter・blur・box-shadow・drop-shadow をアニメーションさせない）
  - ゲーム画面内に出す物は Phaser の Image で、起動時に作った画像を動かす程度。毎フレームの Graphics の描き直しはしない
  - 強さの変化は変わった時だけ表示を切り替える。テクスチャは必要になった時に1回だけ読む

## 成功基準
- パワーアップ中に本人の画面にだけ出て、解除で消える。観戦・他人の画面には出ない
- 852×393 DPR3・915×412 DPR2.625・1600×900・1920×1080 で、立ち絵 右/左それぞれ、パワーアップ1と MAX のスクショ。上の「かぶせない」ものに重ならない
- パワーアップ中と通常時で、?perf=1 の値・スタイル再計算／レイアウトの回数（perf5 と同じ計り方）が大きく増えない（前後の表）
- typecheck・test:server・e2e（全体1回）が通る。e2e は増やさない

## 不明なら止めて聞く
- エフェクトの見た目の方向（光・オーラ以外の案を出したい場合）
- PC で視界外に置く場所が取れない場合

範囲外の変更、不要な抽象化、素材の加工、e2e の追加、公開サーバーの停止
