## 成功基準

### A. 不具合：リコール（撤退）
1. リコールのチャージ中に「移動・攻撃（通常攻撃・技）・被弾」のいずれかが起きたら中断し、チャージは0に戻る。今は移動しながら貯まる
2. リコール完了時に最大HPの50%を回復（最大HPで頭打ち）。割合は定数1か所

### B. UI：撃破カットイン
3. 自分が撃破した時以外のカットイン（味方・敵の撃破、自分が撃破された時）で、キャラ名・攻撃手段の文字が立ち絵の顔に被っている（例：「もち子／ファンネル」が顔の上）。自分が撃破した時の演出と同じく、文字は画面中央に出し、顔と重ならない配置にする
4. 自分が撃破した時の演出は変えない。立ち絵の加工はしない（位置・サイズのみ）

### C. バランス
5. 技の向き：技は向いている方向ではなく、通常攻撃と同じ照準ルール（照準ボタンの設定：一番近い敵など）で対象の敵へ向けて撃つ。対象がいないときの挙動は通常攻撃と同じにする
   - 現在向き依存なのは Whitecul の吹雪、ユーレイちゃんのビーム、ビィのデッドリーウェイブ。他にも向き依存の技があれば一覧で報告し同様に直す
6. ビィのデッドリーウェイブ：突進中は通常攻撃によるダメージを受けない（技のダメージは受ける）
7. きりたんの技：発射弾数を現行の2倍。発射時間は変えず発射密度を2倍にしてDPSを2倍にする
8. ひまりの技：クールタイム+3秒。アシストへのダメージを半分（コード上の「アシスト」が何を指すか確認し、報告に書く）
9. パワーアップ中も技を使えるようにする
10. パワーアップのシールド（コード上の正式名称を報告）：Lv4を現Lv3の値にし、Lv2・Lv3も同じ比率（現Lv3÷現Lv4）を掛けて減らす。Lv1は据え置き。変更前後の値を表で報告

### D. 実況
11. フォーカス変更時、場所のセリフと状況のセリフを短くまとめて出す。順番は次の2型をランダム（50/50、定数）
   - 型1：状況 → 場所（例：上の廊下を実況中 →「ひまりとめたんが接敵！」→「エントランスも激しい戦いだ！」）
   - 型2：場所 → 状況（例：「緑のミーティングルームでは」→「ひまりとめたんが接敵！」）
   - 場所のセリフは現行（例「緑のミーティングルームでも動きがあります」）より短くする。型1用（感嘆の短文）と型2用（「〜では」の前置き）の2種を各場所に持つ
   - 現状、場所のセリフを言っている間に状況が落ち着き、状況のセリフが捨てられている。状況のセリフはフォーカス変更とひとまとまりで扱い、場所のセリフ再生中に捨てない
12. 「（数字）人で戦っています」が「人で戦っています」と読まれ数字が抜けている。人数ごとに数詞込みのテンプレ（ひとりで／ふたりで／さんにんで／よにんで／ごにんで…最大人数まで）を持つ
13. 「攻め時です」を「せめじ」と読んでいる。「せめどき」に固定
14. 12・13は台本ファイル側で読みを固定。`npm run cm:vvproj` で vvproj を更新し、既存項目の調声を消さない。docs/commentary_readings.md も更新。新規の部品・セリフ（11の場所の短文、12のテンプレ）は vvproj に入れたところで止めて報告（本人が調声する）。音声生成は本人の「調声済み」の指示の後
15. 台本仕様（commentary_lines.md）と矛盾する箇所はこの書類を優先。リポジトリ内の台本ファイルも合わせて更新
