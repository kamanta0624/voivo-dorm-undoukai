## 症状（本人、iPhone 15 Pro・live-20261126-12）
- 横持ち：結果画面の下半分（味方／相手・大将ダメージ／徳のタブと表）が画面の下にはみ出して見えない
- 縦持ち：結果画面が縦向きのまま表示され、右側が切れる。縦で表示できること自体が NG

## 仕様（本人）
- 結果画面はゲーム画面と同じく、画面サイズに合わせて全部が1画面に収まる（スクロールしないと見えない部分を作らない）
- 縦持ちでは結果画面を出さない。他の画面と同じ「横にしてください」を出す（result1 で決めた「開いた後に縦にしても読める」は取り消し）

## やること
- 結果画面全体（見出し・推移グラフ2段・タブ・表）を、表示領域の幅と高さの両方に収まるように縮める。ゲーム画面の拡大縮小と同じ考え方でよい（縦横比を保って全体を縮める等。やり方は Code が決めて報告）
- 縮めても文字は 10px 未満にしない。収まらない場合は、グラフの高さを詰める・表の行の高さを詰めるなど配置で調整する。それでも無理なら案を出して止める
- 縦持ちの時は結果画面を隠し、ゲームと同じ「横にしてください」を出す。横に戻したら開いていた結果画面がそのまま出る
- iPhone の実機の表示領域で確かめる。result1 のスクショ（852×393）では収まっていたが実機ではみ出したので、原因（ホーム画面に追加した PWA の表示領域、アドレスバー、100vh の扱いなど）を特定して報告
