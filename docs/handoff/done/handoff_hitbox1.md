# Code引き継ぎ：hitbox1（視界・射程・当たり判定を、足元の点から体全体へ）

2026-11-27 Chat作成。対象：~/kiritan_zunda_proto。shot1 の後にやる（shot1 の計測をそのまま使う）。不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。

## 仕様（本人）
- 視界：体の一部分でも視界にかかったら見える
- 射程：体の一部分でも射程にかかれば攻撃の対象にしてよい
- 当たり判定（ヒットボックス）：同様に体全体
- 狙い：今より当たりやすくする

## 今の作り（Chat がコードで確認。Code も確かめること）
- 視界：visibleTo は足元の1点（p.x, p.y）が視界の円の中で、目から見通せるかだけを見ている
- 射程：pickTarget は足元どうしの距離 ≤ 射程 ＋ 相手の半径（プレイヤーは PLAYER_RADIUS 10）
- 弾の当たり：updateShots は足元を中心とした半径（t.r ＋ BULLET_RADIUS）の円
- 見た目のドットは 32×42（DOT_SCALE 倍。アシスト・大将は2倍）で、足元から上へ伸びている。判定は足元の小さな円だけ

## やること
1. **体の箱を決める**：足元を下辺の中央とする長方形（幅・高さ）を、表示倍率（プレイヤー1・アシスト／大将2・コバコなど）ごとに CONFIG に置く。値はドット絵の不透明な部分の大きさから Code が決め、根拠を報告（キャラ別にはしない。全キャラ共通）
2. **視界**：敵の体の箱の一部でも、視界の円に入っていて目から見通せれば見える。箱の数点（四隅・中心・足元など）で調べる形でよい。サーバーの送る・送らない（visibleTo）と、画面のフォグの両方をそろえる。足元が霧の中でも頭が見えていれば、敵は送られて頭が描かれる
3. **射程**：自分の足元から相手の体の箱までの一番近い距離 ≤ 射程、で対象にする（オートアタックの対象選び・技の対象選び・射程の円の考え方）。近接の扇形は、扇と体の箱が重なれば当たり
4. **当たり判定**：弾・矢と、範囲攻撃（円・長方形・扇）は、体の箱と重なれば当たり
5. 対象は、体を持つもの全部（プレイヤー・アシスト・大将・コバコ・ユニット扱いの場の物）。大将はもともと「当たり判定が無い」設定の部分があれば、それは変えない
6. **変えないもの**：移動の当たり（壁との衝突・押し出しは今の足元の円のまま）、アイテム・資材の取得判定、自分中心の範囲の起点（体の中心のまま）、近接の巻き戻し判定の仕組み（箱は巻き戻した足元に付いて動く）
