## 第1部：技変更（花丸パンチ・オーバーロード・ジャッジメント）

### 1. 満別花丸：技名「花丸パンチ」（旧：巨大拳飛ばし／読み てんきょうけん → はなまるぱんち）
- 技ボタン長押しでゲージが溜まる。離した瞬間に発射
  - タメなし（押してすぐ離す）＝レベル1＝現状の拳そのまま
  - 3秒ホールド→レベル2、6秒ホールド→レベルmax（3）。max以降は溜まらない
- レベルが上がるほど拳のサイズと威力が上がり、弾速が遅くなる。倍率は仮置き（例：Lv2 サイズ1.5・威力1.5・弾速0.75、Lv3 サイズ2・威力2.2・弾速0.55）
- タメ中は通常どおり移動可
- タメ中のゲージ表示とレベル到達の分かる表示（自分に見えれば可、敵に見えてよいかは現状の他技に合わせる）
- 壁破壊・貫通、壁押し込みパッシブ、1キャラ1回ヒットは現状維持
- スマホ：技ボタン長押し＝タメ、離す＝自動照準で発射（短押しは今と同じ）
- Bot：適当なタメで撃てばよい（強さは求めない）

### 2. 猫使ビィ：技名「オーバーロード」（旧：再現江湖／読み でっどりーうぇいぶ → おーばーろーど）
- 発動で固定時間（仮3秒）オーバーロード状態
  - 移動速度アップ（仮×1.6）、通常攻撃しない
  - 0.2秒ごとにその場に残像を置く。残像は敵の通常攻撃・自動照準の対象になるおとり。1秒経過か攻撃を受けると消える
  - ビィが敵キャラに触れると、その敵が「ダメージ予約」状態になる（予約中の目印を表示）。同じ敵には1回のオーバーロードで1回だけ
  - 予約はビィ個体ごとに区別する（同じチームに別のビィがいても別管理）
- オーバーロード終了時、予約が1人以上いれば：ビィがポーズ（立ち絵ではなくドットの既存コマで可、無ければ確認）→一瞬硬直（仮0.5秒）→セリフ「ばくはつ！」と同時に予約中の全員へダメージ（仮値）。予約0人ならポーズも硬直もなし
- オーバーロード中・硬直中にビィが倒されたら予約は消滅、ダメージ不発
- 旧技の突進・着弾爆発・壁破壊は削除
- 「ばくはつ！」の音声は既存のキャラボイス再生の仕組みで鳴らす。ビィの声の生成・置き場が今の仕組みで扱えない場合は確認しろ。字幕・吹き出しの出し方も既存に合わせる
- スマホ：タップで発動
- Bot：敵が近いときに発動して敵へ寄ればよい

### 3. ユーレイちゃん：技名「ジャッジメント」（旧：エンマビーム／読み えんまびーむ → じゃっじめんと）
- 性能は変えず、弾速だけ25%上げる（chars.ts の yurei skill.speed 420 → 525）
- コメント・説明文の旧技名も新名へ

### 4. 共通
- 技名・読みは技名定義を変えるだけで選択画面・キルログ・撃破表示・実況字幕が追従すること（ハードコードがあれば定義参照へ直す）
- 実況の技名の読み（てんきょうけん／でっどりーうぇいぶ／えんまびーむ）を新しい読みに差し替え。部品音声の作り直しが要るならVOICEVOXプロジェクトも更新
- 状態key・場の物の種類は他キャラと重ねない

### 成功基準
- 花丸：タメなし／3秒／6秒で3段階の拳が出て、サイズ・威力が上がり弾速が落ちる。タメ中に歩ける。PC・スマホ両方
- ビィ：オーバーロード中に加速・AAなし・0.2秒ごとの残像、残像が敵AAを吸って消える／1秒で消える。触れた敵に予約が付き同一敵は1回、終了時にポーズ→「ばくはつ！」→予約全員にダメージ。予約0人なら何も起きない。途中撃破で不発。ビィ2人の予約が混ざらない
- ユーレイちゃん：技名がジャッジメントになり、弾速だけ1.25倍、他の挙動・数値は不変
- verify/server.ts に花丸・ビィの技の検証を追加して通す。golden のハッシュ更新は変更理由を明記
- 型チェック・ビルド・既存検証が通る

## 第2部：キャラ追加「九州そら」

### 1. 基本
- key `sora`、名前「九州そら」。role `attacker`、近接（melee）、walk `hover`
- 移動：倍率なし（attacker は speed 1.0 なので花丸と同じ）
- 通常攻撃：パンチ。花丸よりダメージやや高く、間隔やや長く。仮：`dmg: 0.85`（attacker 1.4倍込みで1発約29、花丸24）、`cd: 1.25`秒
- 素材：32dot PSD・Moiky立ち絵とも九州そらがある。PSDの名前の頭・腰・立ち絵dirと select / ko / koed の表情は現物を見て候補を出し、本人に確認

### 2. 技「ソーラーキャノン」（読み そーらーきゃのん）
#### チャージ
- 試合開始0秒から自動でチャージが進む。撤退でリセット（復帰後に0から再開）
- 発射でチャージを0に戻す。クールタイム5秒（発射から）。CT中もチャージは進む
- 見た目：30秒チャージでそらに小さな光が1つ付く。4分30秒以降は光がたくさんちらつく

#### 照射
- 発射するとそら本人はその場で止まり、向いている方向へ5秒間ビームを照射
- 照射中も向きは少しだけ変えられる。5秒間同じ方向へ動かし続けて30度程度（約6度/秒）
- ビームは多段ヒット。キャラに当たっても止まらない。壊せる壁は破壊して貫通し、そのまま進む。壊せない外壁で止まる。射程の端で止まる
- ビームにはあとから入ってきたキャラにも当たる

#### 爆発（チャージ10秒以上のときだけ）
- ビームが当たったキャラ・壁ごとに、1回の照射で1回だけ爆発する（途中からビームに入ってきたキャラでも爆発する）。射程の端・外壁に着いた点でも1回爆発
- 爆発は範囲内の壁も壊す
- 爆発がいくつ重なっても、1キャラが爆発のダメージを受けるのは1照射で1回だけ

#### チャージ量と性能（仮置き。キーフレーム間は線形補間）
「総ダメージ」は5秒間ビームに入り続けた場合のビーム合計＋爆発1回。attacker の大将ダメージ2倍（ATTACKER_BOSS_MULT）を掛ける前の値。

| チャージ | 総ダメージ | 射程(px) | 爆発半径(px) |
|---|---|---|---|
| 5秒（CT明けの即撃ち） | 29（通常攻撃1発程度） | 200 | なし |
| 10秒 | 45 | 300 | 爆発が出始める（0から） |
| 30秒 | 80 | 450 | 40（キャラ2人分） |
| 4分30秒（270秒） | 110 | 550 | 60 |
| 4分55秒（295秒）以降は上限 | プレイヤーへ250、大将へは別枠で最終1200（下記） | 外壁まで | 200（ミーティングルーム svcA 288×272 の外接円。部屋割り変更後の会議室基準で要再計算） |

#### 最大チャージの大将への威力（決定）
- 最大チャージの照射＋爆発が大将に与える合計は、全倍率（ATTACKER_BOSS_MULT・DAMAGE_MULT など）を掛けた後の最終値で1200（BOSS_HP 1000）。大将用の値を別に持ち、倍率を逆算して設定する
- ビームが大将に当たっている間は、大将の拠点移動（BOSS_MOVE_THRESHOLD による予告→広範囲攻撃→移動。この間の無敵も含む）を起こさせない
- 狙い：試合開始からチャージし、4分54秒〜4分56秒にマップの対角線の端から敵の大将へ撃つと、HP満タンの大将がワープできず、試合終了（MATCH_TIME 300秒）の直前に撃破される
- このために、キーフレームの時刻（最大到達を294秒に前倒し等）、照射中のダメージの入り方（時間配分）、爆発のタイミング、ビームの射程（対角線約3700px を届かせる）を微調整してよい
- 検証：大将HP満タン・そらをマップの対角の端に置き、チャージ294・295・296秒相当で大将へ発射→いずれも大将がワープせず、試合終了前に撃破されること

- 30秒〜4分30秒は伸びを鈍らせる（性能向上の一時的な低減）、4分30秒から再び急上昇
- 総ダメージのビーム：爆発の配分は仮でビーム6：爆発4。ビームの多段は同じ相手へ0.25秒おき

### 3. 操作・Bot
- PC・スマホとも技ボタンで発射（向きの決め方は既存の技と同じ）。照射中の向き変更は移動入力で
- Bot：チャージ10秒以上でビームの線上に敵か大将がいれば撃つ程度でよい（強さは求めない）
- E2E_BOTS には入れない（壁破壊で検証が揺らぐため、ビィ・ひまりと同じ扱い）

### 4. 共通
- 実況の技名定義（commentary_script.json）に name・yomi を追加。実況の部品音声が要るならVOICEVOXプロジェクトも更新
- 状態key・場の物の種類は他キャラと重ねない
- キャラボイス台本・雑談は今回の対象外

### 成功基準
- 選択画面にそらが出て、hover移動・パンチの通常攻撃が動く
- 試合開始からチャージが進み、撤退でリセット、発射で0に戻る。CT5秒中もチャージが進む
- 照射中は本人が止まり、5秒で最大約30度だけ向きが変わる
- ビームがキャラを貫通し、壊せる壁を壊して進み、外壁で止まる
- チャージ10秒未満は爆発なし。10秒以上で、キャラ・壁ごとに1照射1回の爆発、1キャラへの爆発ダメージは1照射1回
- 30秒で光が1つ、4分30秒以降は光がちらつく
- 4分54秒〜4分56秒チャージで対角線の端から撃つと、満タンの大将がワープせず試合終了直前に撃破される（verify に検証を追加）
- verify/server.ts にソーラーキャノンの検証を追加して通す。型チェック・ビルド・既存検証が通る。golden の更新は理由を明記

## 第3部：アシスト追加「波音リツ」

### 1. 位置づけ
- アシスト（選べないキャラ）。既存の kurono・shirakami・aoyama と同じ仕組み（config.ts の ASSIST.units、GameRoom.ts の summonAssist・updateAssists・maxHp・移動速度）に4人目として足す
- 召喚の抽選対象に入る（summonAssist は units からランダム）
- 素材：ドットだけ（tools/make_dot.py に追加）。32dot PSD に波音リツがあるか、名前の頭・腰を確認し、無ければ確認しろ。chars.json への登録も既存アシストに合わせる

### 2. 性能
- 高耐久・鈍足：他アシスト比で HP2倍・移動速度0.5倍（仮）。今は ASSIST.hp・ASSIST.speed が全アシスト共通なので、ユニットごとの倍率（例 units.ritsu.hpMult・speedMult）を足して maxHp と移動速度で掛ける。他アシストの値は変えない
- 吹雪：周囲に敵（プレイヤー・大将）がいるときだけ、一定間隔で発動（玄野と同じ条件・間隔の仕組み）
  - 発動時に玄野と同じく予告（仮1秒、自分中心で付いていく）→ 自分中心の円にダメージ＋外向きにはじく
  - 仮：sense 200、every 6、r 128、warn 1、dmg 30、push 60。ダメージは強さ（POWER_MULT）を掛ける。はじき距離は掛けない
  - 大将ははじかれない（既存の push の仕様どおり）
- 重い：リツ自身ははじかれない（めたんのドリル・WhiteCULの吹雪とも。push を無効にする）
- めたんのドリルがリツに当たったとき：リツへのダメージは通常どおり入り、逆にめたんがリツから離れる向きへ、ドリルのはじき距離（metan.skill.push）分はじかれる。同じ相手への再ヒット間隔（rehit）に合わせ、ドリル中に何度もはじかれる
- WhiteCULの吹雪がリツに当たったとき：ダメージは入り、はじきなし（WhiteCULは弾き返されない）

### 3. 見た目・実況
- 吹雪の見た目は WhiteCUL の吹雪の色（blizzard）を流用した円で可
- 実況の名前・読み（なみね りつ）を既存アシストと同じ定義へ追加。部品音声が要るならVOICEVOXプロジェクトも更新
- 召喚・強化の通知、撃破表示などは既存アシストと同じ流れで出ること

### 成功基準
- アシスト召喚でリツが出ることがある（検証では指定召喚でよい）
- リツのHPが他アシストの2倍、速度が0.5倍。他アシストの値は不変
- 周囲に敵がいるときだけ、予告→自分中心の吹雪でダメージ＋はじき。敵がいなければ発動しない
- めたんのドリル・WhiteCULの吹雪でリツが動かない。ドリルが当たるとめたんがはじかれ、リツにダメージは入る
- verify/server.ts に上記の検証を追加して通す。型チェック・ビルド・既存検証が通る。golden の更新は理由を明記
