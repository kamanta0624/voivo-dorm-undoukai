# Claude Code への指示（そのまま貼る）

『ブイブイブレイカーズ（V V BREAKERS）』の X 投稿用ティザー動画を、公開ビルド https://vv.club-daiman.com から撮影してください。同梱の `handoff-2026-11-26.md` を先に読み、`scripts/` の撮影スクリプトを使ってください。

手順：
1. `scripts/lib.mjs` を Mac 向けに直す（メモの「Mac 向けに直す箇所」参照：CHROME パス、proxy 削除、createRequire のパス）
2. `scripts/fpsprobe.mjs` を実行し、描画 fps が約60出ることを確認する。出なければ撮影に入らず、その数値を報告する
3. 練習モード（1vs1）で場面を作り、10場面（メモ参照）を各5〜10秒・1280×720で録画する。壁破壊は `p_wall3.mjs` が実績のある台本、他は同梱の下書きを土台に
4. 各クリップは開始／中間／終了の3フレームを抜いて、主役が画面中央付近に映っているか目視確認する。見せ場の直前は約2.3秒静止してカメラを落ち着かせる（`settle()`）。ダメなカットは撮り直す
5. webm から ffmpeg で mp4 に変換し、`01-select.mp4` のような連番ファイル名で1フォルダにまとめる

制約：
- 本番サーバーへの同時接続は1クライアントのみ
- 撮れなかった場面は捏造せず、正直に報告する
- 公開ビルドのタイトル画面はまだ旧タイトル「VOICE SQUAD」表示なので、タイトルが映るカットは避ける
- ゲームのコードや公開ビルドには一切手を入れない（撮影のみ）
