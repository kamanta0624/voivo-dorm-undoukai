# Code引き継ぎ：pwfx1（自キャラのパワーアップ中の画面演出）

2026-11-24 Chat作成。前提：handoff_vision1（視界の全体短縮）完了後に着手（視界外の空きが広がってから配置を決める）。
不明点は勝手に判断せず本人に確認。範囲外のコード・コメントは変えない。素材（Moiky 立ち絵・32dot）は加工しない（切り抜き・変形・色変えなし。表示の拡大縮小・位置・透明度だけ）。

## 仕様（本人）
- 自キャラがパワーアップしている間、本人の画面にだけ演出を出す。他人の画面・観戦には出さない
- 使う場所：ゲーム画面の外（スマホの横長画面で 640×360 の外に出る左右の余白など）と、ゲーム画面内の視界の外
- 左側：自キャラの Moiky 立ち絵＋エフェクト（光・オーラなど。パワーアップの強さ 1〜MAX で強くなるとよい）
- 右側：ちびキャラやスチル。素材はまだないので、差し替え用の枠（素材の置き場所とキーを1か所で定義）と仮表示（枠線と「素材待ち」程度、または非表示）だけ作る
- 解除で消える（パワーアップの残り時間・解除の扱いは今の状態の値に従う）

## 守ること
- 視界の円・キルログ域（CONFIG のスロット演出の area.killLog）・自軍の一覧・ボタン類・スティックの操作域にかぶせない。スロットの演出（視界外の隅・特別演出は画面全体の視界外）と同時に出た時の重なり方を決めて報告（例：パワーアップ演出は薄くする、スロットの特別演出の間は隠す）
- ゲームの操作（タップ・クリック）を邪魔しない（pointer-events を通す）
- 軽さ優先（docs/render_policy.md）：
  - ゲーム画面の外（余白）に出す物は DOM（img 等）になる。出す時に1回だけ配置し、動きは CSS の transform・opacity のアニメーションだけで行う（毎フレーム JS で left/top や style を書かない。filter・blur・box-shadow・drop-shadow をアニメーションさせない）
  - ゲーム画面内（視界外）に出す物は Phaser の Image で、エフェクトは起動時に作った画像を動かす程度。毎フレームの Graphics の描き直しはしない
  - 立ち絵・エフェクトのテクスチャは必要になった時に1回だけ読み込み、解除時に表示を消す（読み直さない）
  - 強さ（1〜MAX）の変化は、変わった時だけ表示を切り替える
- PC（16:9 で余白なし）では視界外だけを使う。スマホ横向き（iPhone 15 Pro 相当）では余白も使う

## 成功基準
- パワーアップ中に本人の画面にだけ出て、解除で消える
- 上の「かぶせない」ものに重ならない（スマホ・PC それぞれのスクショで確認、パワーアップ1と MAX の2通り）
- パワーアップ中と通常時で、メインスレッド時間・スタイル再計算／レイアウト・GPU 転送量・drawcall が大きく増えない（計測は perf2〜perf4 と同じハーネス（ヘッドレス Chrome・CPU 4x・Bot 入り試合60秒×2回）で、?perf=1 の値・GPU 転送量・drawcall・メインスレッド時間を前後で比べる（docs/render_policy.md の7））
- e2e が通る
