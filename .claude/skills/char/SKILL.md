# キャラの追加・修正

## 資料
- `docs/char_catalog.md`：一覧。キャラごとの性能・技の組み立て（呼び口・状態・場の物・描画）・素材、技の型ごとの手本
- `docs/add_char.md`：手順。触るファイルと項目、呼び口・状態・場の物の仕様、確認方法

## 進め方
1. `docs/char_catalog.md` を読む。作りたい技に近い手本を「技の型と手本」から選ぶ。状態 key・場の物の種類が既存と重ならない名前を決める
2. `docs/add_char.md` の手順どおりに実装する。共通処理（GameRoom.ts と切り出した server の slot・bot・lobby・snapshot・lagcomp・messages・e2e、main.ts・geom.ts・config.ts）にキャラ key・状態 key・場の物の種類を書かない。技の数値は chars.ts の `skill`、HP・攻撃・移動・視界は `stat` に置く（ロールの倍率・近接補正は無い）
3. `docs/add_char.md` の「確認」を通す。仕様を変えたら verify/golden.txt を取り直す
4. 一覧と手順書を更新する（下）。実装と同じコミットに含める

## 作業後の更新（必須。省略したら未完了）
- `docs/char_catalog.md`
  - 触ったキャラの行を3つの表（性能／技の組み立て／素材）すべてで実装に合わせる。追加なら行を足し、削除なら行を消す
  - 新しい型の技なら「技の型と手本」に1行足す。既存の手本より良い手本になったら差し替える
  - 「更新履歴」に1行（日付・コミットの要約・触ったキャラ）
- `docs/add_char.md`
  - 手順書に無かった手順・はまった点・新しい状態の効果・新しい呼び口を追記する
- 更新後に照合する（差が出たら一覧を直す）

```
diff <(grep -oE '^  [a-z]+: def' src/shared/chars.ts | cut -d: -f1 | tr -d ' ' | sort) <(grep -oE '^\| `[a-z]+` ' docs/char_catalog.md | tr -d '|` ' | sort -u)
grep -hoE "statuses: \[[^]]*\]|ents: \{ [a-z]+" src/server/skills/*.ts
```

1行目は差分なしが正。2行目の状態 key・場の物の種類が、一覧の「技の組み立て」の表と一致すること。

## 守ること
- 素材（32dot PSD・立ち絵）は加工しない。PSD に無い絵は作らない。必要なレイヤーが無ければ止めて聞く
- 指示に無い数値は仮置きし、報告の「自分で決めた点」に書く
- 一覧は簡潔に保つ。数値の細目は chars.ts を正とし、一覧には書き写さない
